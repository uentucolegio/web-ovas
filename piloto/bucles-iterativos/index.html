Para, Mientras y Repetir Mientras Que: cómo lograr que el computador repita el trabajo por ti.

Avanza con las flechas → ↓ o deslizando la pantalla

¿Por qué repetir?

Las estructuras de control iterativas repiten un conjunto de instrucciones de manera automática hasta cumplir una condición: así se optimizan los procesos y se reducen los errores.

En programación usamos Mientras, Repetir Mientras Que y Para para ejecutar instrucciones muchas veces sin escribirlas una y otra vez.

🔄 1. Concepto de iteración

Iterar es ejecutar repetidamente un conjunto de instrucciones, de forma controlada, hasta que se cumpla una condición o se alcance un número de repeticiones.

Secuencial

Una instrucción tras otra, sin saltos ni repeticiones.

Condicional

El programa decide según una condición.

Iterativa

Servir jugo a 5 personas: el mismo proceso, cinco veces.

🔢 2. Ciclo Para (for)

Se usa cuando conoces de antemano cuántas veces se repite. Se basa en tres elementos:

Para i ← 1 Hasta 10 Con Paso 1 Hacer
    // Instrucciones a repetir
FinPara
Valor inicial

Con qué valor arranca la variable: i ← 1.

Condición de fin

Hasta qué valor se repite: Hasta 10.

Actualizador

Cuánto cambia la variable en cada vuelta: Con Paso 1.

🧗 Cada vuelta, un escalón

En Para i ← 1 Hasta 10, cada vuelta sube un escalón. La esfera muestra el valor de i y el resultado de 5 × i.

🔃 3. Ciclo Mientras (While)

Repite mientras una condición sea verdadera. La condición se revisa antes de cada vuelta, así que el bloque podría no ejecutarse nunca.

Variablei = —
Condición¿i ≤ 5?

Ejemplo: imprimir del 1 al 5.

🔎 Descubrimientos 0/6

🔂 4. Ciclo Repetir Mientras Que (Do-While)

Ejecuta el bloque al menos una vez, porque la condición se revisa al final. Es ideal para validar los datos que escribe el usuario.

Repetir
    Escribir 'Ingrese un número mayor que cero: '
    Leer número
Hasta Que número > 0
Escribir 'Número válido ingresado: ', número

🖥️ Pruébalo

Vueltas0

Prueba primero con 0 o con un número negativo.

⚖️ Mientras vs. Repetir: la prueba de fuego

Con x ← 10 la condición es falsa desde el principio. ¿Cuántas veces se ejecuta cada ciclo?

Mientras

x ← 10
Mientras x < 5 Hacer
    Escribir x
FinMientras
1 · ¿x < 5?2 · Escribir x
Ejecuciones del bloque: ?

Repetir Mientras Que

x ← 10
Repetir
    Escribir x
Hasta Que x >= 5
1 · Escribir x2 · ¿x >= 5?
Ejecuciones del bloque: ?

Mientras revisó la condición primero y no se ejecutó ni una vez. Repetir ejecutó el bloque una vez antes de revisarla.

n ← 0
