📱 Diseño Responsivo

📝 El Diseño Responsivo es una técnica de diseño web que permite que una página se adapte automáticamente al tamaño y tipo de pantalla del dispositivo desde el cual se está visualizando: ya sea un computador, una tablet o un celular.


🎯 El objetivo es que el contenido se vea bien organizado, legible y funcional, sin importar si el usuario está en una pantalla grande o pequeña

📘 Guía paso a paso: Mini página personal (Responsive sin variables)

🔹 Paso 1: Crear el proyecto en Visual Studio Code
  • 💻 Abre Visual Studio Code.
  • 📁 Crea una carpeta llamada, por ejemplo, responsive-ejercicio.
  • 📄 Dentro de la carpeta, crea dos archivos:
    • index.html (estructura y contenido).
    • styles.css (estilos y diseño).
  • ✅ Asegúrate de que ambos archivos estén en la misma carpeta, para que se puedan vincular correctamente.
🔹 Paso 2: Construcción del HTML (estructura semántica y contenido)

🏗️ Este archivo define el contenido de la página y la organización de los bloques principales.

📝 Copia este código en index.html:

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8" />
  <!-- Meta viewport: garantiza que en móviles la página se ajuste correctamente -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Página Personal</title>
  <!-- Vinculación con el archivo de estilos -->
  <link rel="stylesheet" href="styles.css" />
</head>
<body>
  <!-- ========== Encabezado ========== -->
  <header class="encabezado">
    <!-- h1: título principal de la página -->
    <h1>Hola, soy Laura</h1>
    <!-- p: subtítulo o descripción corta -->
    <p>Desarrolladora web en formación</p>
  </header>

  <!-- ========== Contenido principal ========== -->
  <main>
    <!-- Sección que contiene las tarjetas -->
    <section class="contenedor">
      <!-- Primer bloque: información personal -->
      <article class="tarjeta">
        <h2>Sobre mí</h2>
        <p>Me apasiona la tecnología, el diseño y la creación de sitios web modernos.</p>
      </article>

      <!-- Segundo bloque: datos de contacto -->
      <article class="tarjeta">
        <h2>Contacto</h2>
        <!-- enlace "mailto" permite abrir directamente el correo -->
        <p>Email: <a href="mailto:laura@example.com">laura@example.com</a></p>
      </article>
    </section>
  </main>
</body>
</html>

📝 Explicación detallada

  • ⚡ <!DOCTYPE html> → indica que el documento sigue el estándar HTML5.
  • 🌐 <html lang="es"> → define el idioma de la página como español.
  • 🧠 <head> → incluye metadatos, configuración de viewport y enlace al CSS.
  • 👤 <body> → contiene lo que realmente verá el usuario.
  • 📢 <header class="encabezado"> → bloque superior con título principal y subtítulo.
  • 🏗️ <main> → área principal del contenido.
  • 📋 <section class="contenedor"> → agrupa las tarjetas, será el grid que ajustaremos con CSS.
  • 🃏 <article class="tarjeta"> → bloques independientes con su propia información.
  • 📧 <a href="mailto:..."> → crea un enlace directo al correo electrónico.
🔹 Paso 3: Construcción del CSS (estilos, grid y responsive)

Este archivo define cómo se verá la página en pantalla.

Copia este código en styles.css:

/* ========== Reset básico ========== */
/* Quitamos márgenes y paddings por defecto y ajustamos box-sizing */
* { 
  margin: 0; 
  padding: 0; 
  box-sizing: border-box; 
}

/* ========== Estilos globales ========== */
body {
  font-family: Arial, sans-serif; /* Fuente general */
  background: #f5f7fa;            /* Fondo gris claro */
  color: #333;                    /* Color de texto base */
  line-height: 1.5;               /* Altura de línea para mejor legibilidad */
}

/* ========== Encabezado ========== */
.encabezado {
  background: #4a90e2;            /* Fondo azul */
  color: #fff;                    /* Texto en blanco */
  text-align: center;             /* Centra el contenido */
  padding: 48px 20px;             /* Espaciado interno */
}
.encabezado h1 {
  font-size: 2rem;                /* Tamaño grande para el título */
  margin-bottom: 10px;            /* Separación del subtítulo */
}
.encabezado p {
  font-size: 1rem;                /* Subtítulo más pequeño */
}

/* ========== Contenedor principal con Grid ========== */
.contenedor {
  max-width: 1100px;              /* Anchura máxima */
  margin: 24px auto;              /* Centrado horizontal con espacio arriba y abajo */
  padding: 0 20px;                /* Espaciado lateral */
  display: grid;                  /* Activa el modo Grid */
  grid-template-columns: repeat(2, 1fr); /* Dos columnas iguales */
  gap: 20px;                      /* Espaciado entre tarjetas */
}

/* ========== Tarjetas ========== */
.tarjeta {
  background: #fff;                          /* Fondo blanco */
  padding: 20px;                             /* Espaciado interno */
  border-radius: 12px;                       /* Bordes redondeados */
  box-shadow: 0 2px 6px rgba(0,0,0,.1);      /* Sombra suave */
}
.tarjeta h2 {
  margin-bottom: 10px;                       /* Espaciado con el texto */
  color: #222;                               /* Texto más oscuro */
  font-size: 1.25rem;
}
.tarjeta a {
  color: inherit;                            /* Mantiene el color del texto */
  text-decoration: none;                     /* Quita el subrayado */
}
.tarjeta a:hover {
  text-decoration: underline;                /* Subrayado al pasar el mouse */
}

/* ========== Responsive: adaptación en móviles y tablets ========== */
@media (max-width: 768px) {
  /* Reducir padding del encabezado */
  .encabezado { padding: 32px 16px; }
  .encabezado h1 { font-size: 1.6rem; }

  /* Pasar de 2 columnas a 1 sola columna */
  .contenedor {
    grid-template-columns: 1fr;  /* Una sola columna */
    gap: 16px;                   /* Menor separación */
    margin: 16px auto;
  }

  /* Ajustar padding de las tarjetas */
  .tarjeta { padding: 16px; }
}

📝 Explicación detallada

  • Reset (* { ... }): elimina estilos por defecto del navegador.
  • Body: define fuente, color base y fondo general.
  • Encabezado: fondo azul, texto blanco, centrado y con espacio interno amplio.
  • Grid en .contenedor:
    • display: grid: activa el layout tipo cuadrícula.
    • grid-template-columns: repeat(2, 1fr): dos columnas de igual tamaño.
    • gap: define separación uniforme entre tarjetas.
  • Tarjetas (.tarjeta): fondo blanco, bordes redondeados, sombra y padding interno.
  • Responsive (@media):
    • Si el ancho ≤ 768px → el grid cambia a 1 columna.
    • Ajusta paddings y tamaños de texto para una mejor experiencia en móviles.
