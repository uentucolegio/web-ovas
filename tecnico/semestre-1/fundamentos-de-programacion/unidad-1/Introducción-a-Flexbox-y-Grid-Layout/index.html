🎨 ¿Qué son Flexbox y Grid en CSS?

📝 Cuando empiezas a construir sitios web más complejos, necesitas herramientas que te ayuden a organizar el contenido de manera precisa y flexible. Aquí es donde entran Flexbox y Grid Layout.


  • 🔹 Flexbox (Flexible Box Layout): permite distribuir los elementos de una forma fluida en una sola dimensión (fila o columna)

  • 🔹 Grid Layout: permite diseñar estructuras en dos dimensiones (filas y columnas), ideal para crear interfaces más complejas.

📐 Flexbox: diseño unidimensional

📦 Flexbox, o el Módulo de Caja Flexible, es un modelo de diseño unidimensional. Esto significa que se enfoca en la disposición de elementos en una sola dimensión, ya sea en una fila o en una columna.

👆Ejemplo práctico aplicando Flexbox


📝 Este ejemplo utiliza Flexbox para organizar tres cajas (divs) de forma horizontal, centradas dentro de un contenedor. El código de este ejercicio está resuelto en los anexos.


📘 Guía paso a paso: Cajas con Flexbox
🔹 Paso 1: Crear la carpeta del proyecto en Visual Studio Code
  • 💻 Abre Visual Studio Code.
  • 📁 Crea una carpeta nueva llamada por ejemplo flexbox-ejercicio.
  • 📄 Dentro de esa carpeta crea dos archivos:
  • - index.html
  • - styles.css
🔹 Paso 2: Construcción del archivo HTML

🏗️ En este paso vamos a preparar la estructura básica de un documento HTML.

  • 📂 Abre el archivo index.html.
  • ✍️ Escribe el siguiente código:
<!DOCTYPE html>
<html lang="es">
<head>
  <!-- Configuración de caracteres -->
  <meta charset="UTF-8">
  
  <!-- Adaptar la vista a dispositivos móviles -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  
  <!-- Título de la pestaña en el navegador -->
  <title>Ejercicio Flexbox</title>
  
  <!-- Enlace al archivo de estilos externos -->
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <!-- Contenedor principal que agrupará las cajas -->
  <div class="contenedor">
    <!-- Cada div es una caja -->
    <div class="caja">Caja 1</div>
    <div class="caja">Caja 2</div>
    <div class="caja">Caja 3</div>
  </div>
</body>
</html>

🔎 Explicación clave:

  • 🔗 <link rel="stylesheet" href="styles.css"> conecta el HTML con el archivo CSS externo.
  • 📦 <div class="contenedor"> es el padre de las cajas, lo usaremos como contenedor Flexbox.
  • 🎨 Cada <div class="caja"> representa una de las cajas verdes que se verán en la pantalla.
🔹 Paso 3: Construcción del archivo CSS

🎨 Ahora le damos estilos a la página y a las cajas.

  • 📂 Abre el archivo styles.css.
  • ✍️ Escribe el siguiente código:
/* Estilos generales del body */
body {
  background-color: #f2f2f2; /* color gris claro de fondo */
  font-family: Arial, sans-serif; /* fuente del texto */
  height: 100vh; /* altura total de la ventana */
  
  /* Usamos flexbox para centrar el contenido en la pantalla */
  display: flex;
  justify-content: center; /* centra horizontalmente */
  align-items: center;     /* centra verticalmente */
}

/* Contenedor que organiza las cajas */
.contenedor {
  display: flex;   /* activa flexbox dentro del contenedor */
  gap: 15px;       /* espacio entre cada caja */
}

/* Estilo visual de cada caja */
.caja {
  background-color: #4CAF50; /* verde */
  color: white;              /* texto en blanco */
  padding: 15px 25px;        /* espacio interno */
  border-radius: 5px;        /* bordes redondeados */
  font-weight: bold;         /* texto en negrita */
  text-align: center;        /* centrar el texto dentro de la caja */
}

🔎 Explicación clave:

  • ⚡ display: flex; en body y en .contenedor son los que hacen posible el uso de Flexbox.
  • 🎯 En el body, Flexbox se usa para centrar el contenedor completo en la pantalla.
  • 📐 En el .contenedor, Flexbox se usa para ubicar las cajas una al lado de la otra con separación (gap).
  • 🎨 .caja define el estilo visual: color, bordes, padding, etc.
🔹 Paso 4: Visualizar en el navegador
  • • Guarda los dos archivos (index.html y styles.css).
  • • Da clic derecho en index.html → "Abrir con Live Server" (si tienes instalada la extensión).
  • • Si no tienes Live Server, abre el archivo directamente en tu navegador con doble clic.
  • • En la pantalla deberían aparecer 3 cajas verdes centradas, iguales al ejercicio de la imagen. ✅

🔲Ejercicio práctico Grid


En este ejercicio, el estudiante construirá una cuadrícula de 3 columnas y 2 filas utilizando CSS Grid.


📘 Guía paso a paso: Cajas con CSS Grid
🔹 Paso 1: Crear la carpeta del proyecto en Visual Studio Code
  • • Abre Visual Studio Code.
  • • Crea una carpeta llamada por ejemplo grid-ejercicio.
  • • Dentro de esa carpeta crea dos archivos:
  • - index.html
  • - styles.css
🔹 Paso 2: Construcción del archivo HTML

En este archivo crearemos la estructura básica con un contenedor padre y sus 6 cajas.

<!DOCTYPE html>
<html lang="es">
<head>
  <!-- Configuración de caracteres -->
  <meta charset="UTF-8">
  
  <!-- Adaptar la vista a dispositivos móviles -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  
  <!-- Título de la pestaña en el navegador -->
  <title>Ejercicio Grid</title>
  
  <!-- Enlace al archivo de estilos externos -->
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <!-- Contenedor principal que usará Grid -->
  <div class="contenedor">
    <div class="caja">1</div>
    <div class="caja">2</div>
    <div class="caja">3</div>
    <div class="caja">4</div>
    <div class="caja">5</div>
    <div class="caja">6</div>
  </div>
</body>
</html>

🔎 Explicación clave:

  • • <div class="contenedor"> será el Grid principal.
  • • Cada <div class="caja"> será un elemento del grid.
🔹 Paso 3: Construcción del archivo CSS

En este paso definiremos el grid con 2 filas y 3 columnas.

/* Estilos generales del body */
body {
  background-color: #f2f2f2; /* fondo gris claro */
  font-family: Arial, sans-serif; /* fuente del texto */
  height: 100vh; /* alto completo de la ventana */
  
  /* Usamos flex para centrar el grid en pantalla */
  display: flex;
  justify-content: center;
  align-items: center;
}

/* Contenedor principal usando Grid */
.contenedor {
  display: grid; /* activamos grid */
  grid-template-columns: repeat(3, 150px); /* 3 columnas de 150px */
  grid-template-rows: repeat(2, 80px);     /* 2 filas de 80px */
  gap: 15px; /* espacio entre cajas */
}

/* Estilo visual de cada caja */
.caja {
  background-color: #6a5af9; /* morado azulado */
  color: white;              /* texto en blanco */
  display: flex;             /* usamos flex solo para centrar el texto */
  justify-content: center;
  align-items: center;
  border-radius: 8px;        /* bordes redondeados */
  font-size: 18px;
  font-weight: bold;
}

🔎 Explicación clave:

  • • display: grid; activa el modelo Grid.
  • • grid-template-columns: repeat(3, 150px); crea 3 columnas iguales de 150px.
  • • grid-template-rows: repeat(2, 80px); crea 2 filas iguales de 80px.
  • • gap: 15px; añade espacio entre las cajas.
  • • .caja usa Flexbox solo para centrar el número dentro de cada caja.
🔹 Paso 4: Visualizar en el navegador
  • • Guarda los dos archivos (index.html y styles.css).
  • • Abre el archivo index.html en tu navegador (clic derecho → "Abrir con Live Server" o doble clic).
  • • Deberías ver 6 cajas distribuidas en 2 filas y 3 columnas exactamente como en la imagen que compartiste. ✅
