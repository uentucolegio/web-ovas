🎨 CSS

📝 CSS significa hojas de estilo en cascada. Es un lenguaje que se utiliza para aplicar colores, tamaños, márgenes, bordes, fondos, alineaciones, tipografía y más a los elementos HTML.


⚠️ Importante:


  • 🏗️ HTML estructura el contenido.
  • 🎨 CSS da estilo y presentación.

🎯 Principales selectores y propiedades

Selector Uso
elemento Aplica estilo a todas las etiquetas de ese tipo
#id Aplica estilo al elemento con ese ID
.clase Aplica estilo a todos los elementos con esa clase

🏗️ Estructura paso a paso de archivo HTML:


📋 Paso a paso de la solución.


  1. 📁 Crea una carpeta para el proyecto (por ejemplo, sobre-mi).
  2. 📄 Dentro de la carpeta, crea dos archivos: index.html y estilos.css.
  3. ⚡ En index.html, escribe la estructura base de HTML5: <!DOCTYPE html>, <html>, <head>, <body>.
  4. 🌐 Configura el idioma en la etiqueta <html lang="es">.
  5. 🔤 En el <head>, agrega la codificación con <meta charset="UTF-8">.
  6. 🏷️ Coloca el título de la pestaña dentro de <title>Sobre mí</title>.
  7. 🔗 Vincula el archivo CSS con <link rel="stylesheet" href="estilos.css">.
  8. 📢 Agrega un encabezado <h1>Hola, soy Ana</h1>.
  9. 📝 Agrega un párrafo <p>Me gusta la programación y aprender cosas nuevas.</p>.
  10. 💾 Guarda ambos archivos y abre index.html en tu navegador.

2) 🎯 ¿Qué hace cada selector y por qué es útil?


a) 🏗️ body { ... }

🎯 Qué selecciona: toda la página (todo lo que está dentro de <body>).

🎨 background-color: #f0f8ff;
Aplica un color de fondo AliceBlue a toda la página. Útil para dar una base visual suave y evitar el fondo blanco puro.

🔤 font-family: Arial, sans-serif;
Define la tipografía global. Todo el texto hereda esta fuente (títulos, párrafos, listas, etc.), salvo que lo cambies en un selector más específico.
⚡ Valor de respaldo: si el sistema no tiene Arial, usará cualquier sans-serif disponible.


b) h1 { ... }

Qué selecciona: todos los encabezados <h1> (título principal de cada página).

color: #2c3e50;
Pone el texto del <h1> en un azul grisáceo oscuro.
Útil para jerarquía visual: el título destaca más que el resto del texto.


c) p { ... }

Qué selecciona: todos los párrafos <p>.

color: #34495e;
Aplica un azul grisáceo un poco más claro que el del <h1>.
Útil para dar contraste: el texto descriptivo es legible y el título sigue destacando.

Igual que el <h1>, los <p> heredan la fuente de body. Aquí solo definimos su color.

Guardamos los cambios de nuestro archivo estilos.css con la combinacion de teclas Ctrl + S.

Guarda ambos archivos y abre index.html en tu navegador y podras ver el resultado de la utlidad del codigo CSS en HTML.
