🌐 HTML

Significa HyperText Markup Language, es decir, Lenguaje de Marcado de Hipertexto. Este es el lenguaje base para crear páginas web y nos permite estructurar el contenido que vemos en Internet: títulos, párrafos, imágenes, enlaces, formularios, botones, entre muchos otros elementos.

💡 Imagina que Pedrito quiere emprender un nuevo negocio: abrir su propia tienda online para vender camisetas personalizadas. Para lograrlo, necesita crear una página web en la que los clientes puedan:


  • 👕 Ver las camisetas en diferentes modelos y colores.
  • 📖 Leer las descripciones y precios de los productos.
  • 🛒 Añadir artículos al carrito de compras.
  • 📝 Finalmente, llenar un formulario para realizar la compra.

🎯 Aquí entra en juego HTML, ya que será la herramienta con la que Pedrito podrá estructurar la tienda online.


🏷️ Principales etiquetas HTML


🎯 Objetivo

Crear una página web que muestre un título Mi primera Tienda OnLine y un párrafo introductorio.

📋 Paso a paso

  1. 0.

    💻 Abre Visual Studio Code y crea un nuevo proyecto para tu tienda online.

  2. 1.

    📁 Crea una carpeta para tu proyecto (por ejemplo, tienda-pedrito).

  3. 2.

    📄 Dentro, crea un archivo llamado index.html.


  4. 3.

    ⚡ Escribe la declaración <!DOCTYPE html> para indicar que usarás HTML5.

  5. 4.

    🌳 Abre y cierra la etiqueta raíz: <html> ... </html>.

  6. 5.

    🧠 Dentro de <html>, crea la sección de cabecera: <head> ... </head>.

  7. 6.

    🏷️ Agrega el título de la pestaña del navegador dentro de <head> con <title>Mi primera Tienda OnLine</title>.

  8. 7.

    👤 Abre el cuerpo del documento con <body>.

  9. 8.

    📢 Dentro del cuerpo, añade un encabezado principal: <h1>Mi primera Tienda OnLine</h1>.

  10. 9.

    📝 Agrega un párrafo explicativo: <p>Este es mi primer sitio Web usando HTML 5</p>.

  11. 10.

    🔚 Cierra <body> y luego <html>.

  12. 11.

    💾 Guarda el archivo y ábrelo en tu navegador (doble clic o arrástralo a la ventana del navegador).


    Nota: Una vez se hayan guardado los cambios debe de desaparecer el punto de la parte superior.

  13. 12.

    ✅ Verifica que tu página se vea correctamente en el navegador.
