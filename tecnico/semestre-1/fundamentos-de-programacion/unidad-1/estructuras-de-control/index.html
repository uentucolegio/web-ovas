🔀 Estructuras de control secuenciales y condicionales

Hasta ahora hemos visto algoritmos cuyos pasos se ejecutan uno tras otro. Pero, ¿qué pasa cuando el resultado de un algoritmo depende de que se cumpla o no una condición? Para eso existen las estructuras de control.

Las estructuras de control determinan el orden en que se ejecutan las instrucciones de un algoritmo. En este tema estudiaremos las estructuras secuenciales, donde las instrucciones se ejecutan en el mismo orden en que están escritas, y las estructuras condicionales (simple, doble y múltiple), que permiten tomar decisiones y ejecutar distintas acciones según se cumpla o no una condición.

✨ Dominar las estructuras de control es el paso que convierte una simple lista de instrucciones en un algoritmo capaz de tomar decisiones. 🧭

🎯 Objetivos de aprendizaje

  • ➡️ Comprender el funcionamiento de las estructuras secuenciales en un algoritmo.
  • 🔀 Aplicar la estructura condicional simple (Si) para tomar decisiones básicas.
  • ⚖️ Aplicar la estructura condicional doble (Si-SiNo) para evaluar dos posibles caminos.
  • 🧩 Reconocer y construir estructuras condicionales múltiples (SI anidados y SEGÚN).

En una estructura secuencial, las instrucciones se ejecutan una tras otra, exactamente en el orden en que fueron escritas, sin saltos ni repeticiones. Es la estructura de control más simple y la base de cualquier algoritmo.

Pseudocódigo

Inicio
Leer base, altura
area <- base * altura
Escribir area
Fin

➡️ Si se cambia el orden de las instrucciones de una estructura secuencial, el resultado del algoritmo puede ser incorrecto o no tener sentido.

La estructura condicional simple (Si) ejecuta un bloque de instrucciones solo cuando una condición es verdadera; si la condición es falsa, el algoritmo continúa sin ejecutar ese bloque.

Pseudocódigo: número positivo

Inicio
Leer n
Si (n > 0) entonces
  Escribir 'Es positivo'
FinSi
Fin

La estructura condicional doble (Si-SiNo) evalúa una condición y ejecuta un bloque de instrucciones si esta es verdadera, o un bloque diferente si es falsa. Siempre se ejecuta uno de los dos caminos, nunca ambos ni ninguno.

Pseudocódigo: aprobación de una nota

Inicio
Leer nota
Si (nota >= 3.0) entonces
  Escribir 'Aprobado'
SiNo
  Escribir 'Reprobado'
FinSi
Fin

⚖️ En un restaurante que aplica un descuento especial los martes, la condición 'día == martes' decide entre dos caminos: aplicar el descuento o cobrar el valor normal.

Cuando existen más de dos posibles caminos, se utilizan estructuras condicionales múltiples. Estas pueden construirse anidando varias estructuras Si dentro de otras, evaluando una condición tras otra hasta encontrar la que se cumple.

Pseudocódigo: clasificación de notas

Inicio
Leer nota
Si (nota >= 90) entonces
  Escribir 'Excelente'
SiNo Si (nota >= 80) entonces
  Escribir 'Sobresaliente'
SiNo Si (nota >= 70) entonces
  Escribir 'Aprobado'
SiNo
  Escribir 'Reprobado'
FinSi
Fin

Cuando se deben evaluar muchas opciones a partir de una sola variable, es más claro usar la estructura SEGÚN (equivalente al 'switch' en programación), que compara el valor de una variable contra una lista de casos posibles.

Pseudocódigo: día de la semana

Inicio
Leer dia
Según dia hacer
  1: Escribir 'Lunes'
  2: Escribir 'Martes'
  3: Escribir 'Miércoles'
  De Otro Modo: Escribir 'Día no válido'
FinSegún
Fin

🔀 La estructura SEGÚN es una alternativa más clara que muchos SI anidados cuando todas las condiciones comparan la misma variable contra valores distintos.

✍️ Actividades

🔞 Actividad 1: Verificación de mayoría de edad (Individual)

Diseña un algoritmo con una estructura condicional simple que lea la edad de una persona y escriba el mensaje 'Es mayor de edad' únicamente si la edad es mayor o igual a 18 años.

📝 Producto esperado: pseudocódigo del algoritmo con la estructura Si correctamente aplicada.

🔎 Enfoque: aplicar correctamente la estructura condicional simple (Si).

👥 Actividad 2: Descuento por cantidad y clasificación por día (Grupal)

En grupos de máximo tres integrantes, resuelvan las siguientes situaciones: (1) diseñen un algoritmo con estructura condicional doble que aplique un 15% de descuento si la cantidad comprada de un producto es mayor a 5 unidades, o cobre el valor normal en caso contrario; (2) diseñen un algoritmo con estructura SEGÚN que, a partir de un número del 1 al 7, escriba el nombre del día de la semana correspondiente.

📝 Producto esperado: pseudocódigo de ambos algoritmos, usando condicional doble en el primero y SEGÚN en el segundo.

👥 Modalidad: trabajo colaborativo en equipos de máximo tres estudiantes.
