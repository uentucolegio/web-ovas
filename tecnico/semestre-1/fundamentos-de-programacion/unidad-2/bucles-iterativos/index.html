🔁 Bucles (Para, Mientras, Repetir Mientras Que)

Las estructuras de control iterativas permiten repetir un conjunto de instrucciones de manera automática hasta cumplir una condición, lo que resulta esencial para optimizar procesos y reducir errores en programación.

Así como en la vida cotidiana repetimos acciones como practicar una rutina de ejercicios, cocinar varias porciones de un plato o revisar correos uno tras otro, en programación utilizamos bucles como Mientras, Repetir Mientras Que y Para para ejecutar instrucciones múltiples veces sin necesidad de escribirlas repetidamente.

✨ Su aplicación facilita desde tareas sencillas, como mostrar tablas de multiplicar o calcular promedios, hasta procesos como validar datos de forma continua o simular la adición de productos en un carrito de compras. 🔄

🎯 Objetivos de aprendizaje

  • 🧠 Comprender el concepto de iteración y las diferencias entre ejecución secuencial, condicional e iterativa.
  • 🔧 Reconocer el papel de las estructuras de control como herramientas para automatizar procesos repetitivos.
  • 🔁 Aplicar los ciclos Para, Mientras y Repetir Mientras Que en la construcción de algoritmos.
  • 🧩 Aplicar estas estructuras iterativas en la resolución de problemas prácticos.

La iteración es el proceso de ejecutar repetidamente un conjunto de instrucciones de forma controlada hasta que se cumpla una condición o se alcance un número específico de repeticiones. En programación, esta técnica permite automatizar tareas repetitivas, optimizar el código y disminuir la probabilidad de errores al no tener que duplicar instrucciones innecesariamente.

Existen tres formas principales de ejecutar instrucciones: la ejecución secuencial (las instrucciones se ejecutan una tras otra sin saltos ni repeticiones), la ejecución condicional (el programa toma decisiones según una condición) y la ejecución iterativa (se repite un conjunto de instrucciones hasta cumplir una condición o un número determinado de repeticiones).

Secuencial

Calentar agua → agregar café → servir. Sin saltos ni repeticiones.

Condicional

Agregar azúcar al café solo si la persona lo prefiere dulce.

Iterativa

Servir jugo a 5 personas repitiendo el mismo proceso hasta completar la cantidad deseada.

El ciclo Para se utiliza cuando se conoce de antemano el número exacto de repeticiones que debe ejecutar un conjunto de instrucciones. Es ideal para recorrer un rango de valores, realizar conteos o ejecutar procesos controlados por un contador. Se basa en tres elementos esenciales: el valor inicial, la condición de fin y el actualizador.

Sintaxis general

Para variable = valor_inicial Hasta valor_final Con Paso incremento Hacer
  // Instrucciones a repetir
FinPara

🔢 En este ejemplo, i inicia en 1, la condición de fin es 'Hasta 10' y el actualizador incrementa i de uno en uno, por lo que el ciclo ejecuta diez repeticiones mostrando 5 x 1 = 5 hasta 5 x 10 = 50.

El ciclo Mientras permite repetir un conjunto de instrucciones mientras una condición sea verdadera. Es ideal para situaciones en las que no se conoce con exactitud cuántas veces debe repetirse el proceso, ya que la cantidad de iteraciones depende del cumplimiento de una condición lógica. A diferencia del ciclo Para, que se controla mediante un contador, el ciclo Mientras se basa en la evaluación de una expresión booleana que determina si el bloque de instrucciones continúa ejecutándose o si finaliza.

Sintaxis general

Mientras (condición) Hacer
  // Instrucciones a repetir
FinMientras

Ejemplo: imprimir del 1 al 5

Inicio
i <- 1
Mientras i <= 5 Hacer
  Escribir 'Número: ', i
  i <- i + 1
FinMientras
Fin

El ciclo Repetir Mientras Que ejecuta un bloque de instrucciones al menos una vez, independientemente de si la condición es verdadera o falsa en la primera evaluación. Esto se debe a que la condición se verifica al final del ciclo, no al inicio, lo que lo diferencia del ciclo Mientras. Es ideal cuando se desea asegurar una primera ejecución antes de validar la condición, como en procesos de validación de entrada de datos.

Sintaxis general

Repetir
  // Instrucciones a ejecutar
Hasta Que (condición)

Ejemplo: validar un número positivo

Repetir
  Escribir 'Ingrese un número mayor que cero: '
  Leer número
Hasta Que número > 0
Escribir 'Número válido ingresado: ', número

✅ Este tipo de ciclo es especialmente útil para validar entradas del usuario o procesos que deben ejecutarse al menos una vez antes de verificar una condición.

Elegir la estructura de control adecuada depende del problema: si el número de repeticiones se conoce de antemano, conviene usar el ciclo Para; si depende de una condición que puede cumplirse en cualquier momento, se recomienda el ciclo Mientras; y si es necesario garantizar al menos una ejecución antes de validar, se debe usar el ciclo Repetir Mientras Que.

🎯 Reconocer qué tipo de bucle usar es tan importante como saber escribir su sintaxis: una elección incorrecta puede generar bucles infinitos o resultados inesperados.

✍️ Actividades

☕ Actividad 1: Tabla de multiplicar con ciclo Para (Individual)

Diseña en PSeInt un algoritmo que, usando un ciclo Para, genere la tabla de multiplicar de un número ingresado por el usuario, mostrando los resultados del 1 al 10.

📝 Producto esperado: pseudocódigo del algoritmo con el ciclo Para correctamente aplicado y su salida esperada.

🔎 Enfoque: aplicar correctamente los tres elementos del ciclo Para (valor inicial, condición de fin y actualizador).

👥 Actividad 2: Validación de datos y menú repetitivo (Grupal)

En grupos de máximo tres integrantes, resuelvan las siguientes situaciones: (1) diseñen un algoritmo con ciclo Repetir Mientras Que que solicite una edad y no permita continuar hasta que el valor ingresado sea mayor que cero; (2) diseñen un algoritmo con ciclo Mientras que simule un menú de una tienda local que siga mostrando opciones mientras el usuario no seleccione 'salir'.

📝 Producto esperado: pseudocódigo de ambos algoritmos, identificando claramente qué tipo de ciclo se usó en cada caso y por qué.

👥 Modalidad: trabajo colaborativo en equipos de máximo tres estudiantes.
