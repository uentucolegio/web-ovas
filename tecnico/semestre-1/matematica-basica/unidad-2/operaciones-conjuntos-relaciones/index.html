Operaciones con Conjuntos y Relaciones

🤔 ¿Qué es un conjunto? Imagina que es una colección o un grupo de cosas que tienen algo en común. En programación y en la vida, agrupamos elementos constantemente: una lista de usuarios, los productos en un carrito de compras, o los ingredientes para una receta.

Podemos pensar en los conjuntos como canastos con cosas dentro 🧺. Las operaciones que aprenderás aquí (unión, intersección, etc.) nos dicen cómo juntar, comparar o separar lo que hay en esos canastos. Esta habilidad es fundamental para manejar datos, filtrar información y resolver problemas lógicos en el desarrollo de software.

Estos conceptos te ayudarán a entender cómo las bases de datos organizan la información, cómo las aplicaciones filtran resultados y cómo se pueden modelar problemas complejos de una manera lógica y ordenada ✨.

Objetivos de aprendizaje

  • 🧠 Utilizar la lógica proposicional y la teoría de conjuntos para modelar y analizar problemas en sistemas computacionales.
  • 🔍 Diferenciar y aplicar las operaciones básicas entre conjuntos: Unión, Intersección, Diferencia y Complemento.
  • 📝 Comprender y representar relaciones entre conjuntos mediante pares ordenados.
  • 💻 Aplicar los conocimientos de conjuntos para resolver ejercicios prácticos contextualizados en escenarios cotidianos y tecnológicos.

Fundamentos Teóricos

Unión ( ⋃ )

Agrupa todos los elementos de dos o más conjuntos, sin repetir ninguno. En desarrollo web, es útil para combinar listas de características o permisos de usuarios.

Ejemplo:

Dos desarrolladores listan los lenguajes que dominan. La unión son todos los lenguajes que el equipo conoce.

Dev1 = {'HTML', 'CSS'} Dev2 = {'CSS', 'JavaScript'} Dev1 ⋃ Dev2 = {'HTML', 'CSS', 'JavaScript'}

Intersección ( ∩ )

Encuentra los elementos que ambos conjuntos tienen en común. Sirve para encontrar tecnologías compartidas entre proyectos o requisitos comunes.

Ejemplo:

Dos equipos de desarrollo necesitan encontrar qué framework de Front-End usan en común para colaborar.

EquipoA = {'React', 'Vue'} EquipoB = {'Angular', 'React'} EquipoA ∩ EquipoB = {'React'}

Diferencia ( − )

Identifica los elementos que están en el primer conjunto pero no en el segundo. Es ideal para validaciones, como encontrar clases CSS que faltan en un elemento.

Ejemplo:

Un componente debe tener ciertas clases CSS para funcionar. Queremos saber cuál le falta.

ClasesRequeridas = {'card', 'shadow', 'rounded'} ClasesDelElemento = {'card', 'rounded'} ClasesRequeridas − ClasesDelElemento = {'shadow'}

Complemento ( A' )

Son los elementos que no están en nuestro conjunto, pero sí en un conjunto universal (U). Ayuda a saber qué características no soporta un navegador de un total posible.

Ejemplo:

De todas las nuevas características de CSS, ¿cuáles no son soportadas por un navegador específico?

Universo_FeaturesCSS = {'Flexbox', 'Grid', 'WebP', 'AVIF'} SoporteNavegador = {'Flexbox', 'Grid', 'WebP'} SoporteNavegador' = {'AVIF'}

Una relación es una conexión entre los elementos de un conjunto y los de otro. En programación, esto es la base de las bases de datos relacionales (SQL) y los mapeos de objetos (ORM).

Ejemplo: Relación "Experto En"

Podemos relacionar un conjunto de desarrolladores con los lenguajes en los que son expertos.

Desarrolladores = {'Ana', 'Luis', 'Marta'} Lenguajes = {'Python', 'JavaScript', 'Java'}

La relación R se escribiría como pares ordenados:

R = { (Ana, JavaScript), (Luis, Python), (Marta, Java) }

Actividades prácticas

Ejercicio 1. Operaciones con cultivos

Situación: Dados dos conjuntos de cultivos:

A = {arroz, maíz, yuca}

B = {maíz, frijol, papa}

Tu tarea: Encuentra A ∪ B, A ∩ B y A - B.

Ejercicio 2. Relación de deportes

Situación: En una escuela, hay un grupo de estudiantes y los deportes que practican.

Estudiantes = {Julián, Natalia, Sofía, Mateo}

Deportes = {fútbol, atletismo, ciclismo}

Tu tarea: Inventa una relación donde algunos estudiantes practican más de un deporte y escríbela como un conjunto de pares ordenados.

Ejercicio 3. Relación de múltiplos

Situación: Tienes dos conjuntos de números.

A = {1, 2, 3, 4, 5}

B = {2, 4, 6, 8, 10}

Tu tarea: Crea una relación que conecte cada número de A con los números de B que son sus múltiplos. (Ej: 2 se relaciona con 2, 4, 6, 8, 10). Escribe todos los pares ordenados.
