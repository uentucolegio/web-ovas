Sentencias DML y operaciones CRUD

El lenguaje de manipulacion de datos (DML) permite interactuar con la informacion almacenada en una base de datos. Mientras DDL define las tablas, DML permite agregar, consultar, actualizar y eliminar los registros que utiliza una aplicacion.

  1. 🆕CREATE (INSERT): agrega un nuevo pedido o registro.
  2. 🔎READ (SELECT): consulta los pedidos y datos disponibles.
  3. 🛠️UPDATE: modifica el estado o los datos de un registro.
  4. 🗑️DELETE: elimina registros o aplica un borrado logico.

✨ Dominar CRUD permite transformar una base de datos estatica en una experiencia de usuario dinamica, segura y actualizada.

Objetivos de aprendizaje

  • 📝Ejecutar operaciones INSERT, SELECT, UPDATE y DELETE utilizando sintaxis SQL estandar.
  • 🔍Validar la integridad de la informacion mediante clausulas de filtrado y condiciones.
  • 🎯Integrar la manipulacion de datos en escenarios practicos de una aplicacion.
