⚡ Dale vida a tu frontend con JavaScript

Después de construir la estructura visual del frontend con HTML5 y CSS, tu proyecto web cuenta con pantallas que pueden verse en el navegador. Sin embargo, una interfaz no debe limitarse a mostrar contenido estático. Para que el usuario pueda interactuar con formularios, botones, mensajes y datos, es necesario incorporar comportamiento mediante JavaScript.

JavaScript permite que una página responda a las acciones del usuario. Por ejemplo, puede mostrar u ocultar información, validar campos de un formulario, cambiar mensajes en pantalla, cargar datos desde una fuente externa o enviar información a un servicio. En esta guía trabajarás el uso básico de JavaScript desde el frontend, manteniendo el enfoque en la interacción y el consumo simple de APIs.

Esta guía corresponde al tercer tema de la Unidad 2. En ella abordarás eventos, manipulación básica del documento, validación de formularios, mensajes al usuario, peticiones HTTP, respuestas JSON y actualización de la interfaz. El propósito no es desarrollar todavía toda la lógica del backend, sino preparar el frontend para comunicarse con datos o servicios.

Al finalizar, tu equipo entregará una versión funcional del frontend con interacciones básicas, validación de formularios y al menos un ejemplo de consumo simple de API o datos simulados ⚡. Esta evidencia cierra la Unidad 2 y te prepara para la Unidad 3, enfocada en backend, integración, pruebas y despliegue.

✨ No necesitas construir todavía el backend completo: basta con que el frontend reaccione, valide y muestre datos de forma clara. 🚀

Objetivos de aprendizaje

  • ⚡ Reconocer el papel de JavaScript en la construcción de interfaces web interactivas.
  • 🖱️ Aplicar eventos básicos de JavaScript para responder a acciones del usuario dentro del frontend.
  • ✅ Validar formularios del proyecto web antes de enviar o procesar la información ingresada.
  • 💬 Mostrar mensajes de error, confirmación o advertencia que orienten al usuario durante la interacción.
  • 🌐 Realizar consumo simple de APIs desde el frontend mediante peticiones HTTP básicas.
  • 🔄 Actualizar elementos de la interfaz a partir de respuestas obtenidas en formato JSON, sin profundizar todavía en la implementación del backend.
