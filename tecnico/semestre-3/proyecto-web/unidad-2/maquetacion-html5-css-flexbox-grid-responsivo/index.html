🏗️ Del diseño al código: hora de maquetar

Después de diseñar los wireframes, el prototipo navegable y la guía de estilos, tu equipo ya cuenta con una representación visual inicial del proyecto web. El siguiente paso consiste en convertir esas ideas de diseño en una estructura real de frontend, utilizando HTML5 para organizar el contenido y CSS para definir la apariencia visual de las páginas.

La maquetación es una etapa fundamental porque permite pasar del diseño al código. En esta fase, las pantallas dejan de ser solamente esquemas o prototipos y comienzan a transformarse en archivos web que pueden abrirse en un navegador. Para lograrlo, es necesario usar etiquetas HTML de manera ordenada, aplicar estilos CSS coherentes con la guía de estilos y organizar los elementos mediante técnicas como Flexbox y Grid.

Esta guía corresponde al segundo tema de la Unidad 2. En ella abordarás la estructura semántica en HTML5, hojas de estilo CSS, el modelo de caja, Flexbox, Grid y diseño responsivo, con actividades prácticas para construir una primera versión estática de las pantallas principales de tu proyecto.

Al finalizar, tu equipo entregará una versión maquetada del frontend con estructura HTML5, estilos CSS, distribución mediante Flexbox o Grid y evidencias de adaptación responsiva 📱💻 — la base para la tercera guía de la unidad, orientada a JavaScript, validación de formularios y consumo simple de APIs.

✨ No necesitas conectar nada a una base de datos todavía: solo que las pantallas se vean bien, tengan una estructura clara y respeten la guía de estilos de tu equipo. 🚀

Objetivos de aprendizaje

  • 🏗️ Reconocer la maquetación web como el proceso de convertir los diseños y wireframes en una estructura visual construida con HTML y CSS.
  • 🏷️ Aplicar etiquetas semánticas de HTML5 para organizar el contenido de las páginas principales del proyecto web.
  • 🎨 Utilizar reglas básicas de CSS para definir colores, tipografías, tamaños, márgenes, espaciados y apariencia visual de la interfaz.
  • 🧩 Emplear Flexbox y Grid como herramientas de distribución de elementos dentro de la página web.
  • 📱 Implementar criterios básicos de diseño responsivo para adaptar la interfaz a celulares, tabletas y computadores.
  • 💻 Construir una primera versión estática del frontend a partir de los wireframes y la guía de estilos definidos en la guía anterior.
