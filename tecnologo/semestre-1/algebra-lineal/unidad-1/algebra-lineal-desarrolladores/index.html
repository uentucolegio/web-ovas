Producto Escalar: ¿Estamos en sintonía?

El Producto Escalar (o punto) nos dice cuánto de un vector "se proyecta" sobre otro. El resultado es siempre un número, no una flecha.

Algoritmo Manual:

  1. Multiplica los componentes $x$ entre sí.
  2. Multiplica los componentes $y$ entre sí.
  3. Multiplica los componentes $z$ (si existen) entre sí.
  4. Suma todos los resultados anteriores.
$$\mathbf{u} \cdot \mathbf{v} = u_x v_x + u_y v_y + u_z v_z$$
💡 Tip Didáctico: Si el resultado es 0, los vectores forman una "L" perfecta (son perpendiculares). ¡Útil para detectar colisiones laterales!
2

Producto Vectorial: Creando el "Arriba"

A diferencia del anterior, el Producto Cruz nos entrega un Vector. Este nuevo vector siempre es perpendicular a la superficie formada por los dos originales.

La Regla de la Mano Derecha ✋

Si tus dedos siguen la dirección de $\mathbf{u}$ y luego cierran hacia $\mathbf{v}$, tu pulgar apuntará en la dirección del producto $\mathbf{u} \times \mathbf{v}$. ¡Es la brújula del 3D!

Cálculo por Determinante

$$\mathbf{w} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ u_x & u_y & u_z \\ v_x & v_y & v_z \end{vmatrix}$$

Este método nos da los componentes exactos para programar el rebote de una bala o el reflejo del agua.

Traduciendo a Código

Para un desarrollador, la matemática es una función. Aquí tienes cómo implementar estos "motores" de cálculo en Java:

// Método para el Producto Escalar (Dot Product)
public double calcularPunto(double[] u, double[] v) {
    double resultado = 0;
    // Iteramos por cada dimensión (X, Y, Z...)
    for (int i = 0; i < u.length; i++) {
        resultado += u[i] * v[i]; // Acumulamos la sumatoria
    }
    return resultado;
}

// Método para el Producto Vectorial (Solo en R3)
public double[] calcularCruz(double[] u, double[] v) {
    double[] w = new double[3];
    // Aplicamos la fórmula del determinante
    w[0] = (u[1] * v[2]) - (u[2] * v[1]); // Componente X
    w[1] = (u[2] * v[0]) - (u[0] * v[2]); // Componente Y
    w[2] = (u[0] * v[1]) - (u[1] * v[0]); // Componente Z
    return w;
}
