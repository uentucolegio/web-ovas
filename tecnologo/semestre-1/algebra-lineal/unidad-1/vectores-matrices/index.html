Vectores y Matrices: El lenguaje de los datos

🤔 ¿Alguna vez te has preguntado cómo una imagen digital sabe de qué color es cada uno de sus puntos? ¿O cómo un videojuego recuerda la posición de miles de enemigos simultáneamente?

En el desarrollo de software, un vector no es solo una flecha en un papel; es una lista ordenada de datos (arreglo unidimensional). Una matriz no es solo una tabla de números; es una rejilla de datos (arreglo bidimensional) que permite representar desde un mapa hasta bases de datos complejas.

"Aprenderás a definir estos objetos matemáticamente y a implementarlos lógicamente en Java para modelar situaciones computacionales y gráficas."

Un vector es una $n$-tupla ordenada de números reales. Matemáticamente, un vector $\mathbf{v}$ en un espacio de $n$ dimensiones se representa como:

$$\mathbf{v} = [v_1, v_2, v_3, \dots, v_n]$$

En el ámbito del software, a cada elemento $v_i$ se le conoce como un componente y a su posición dentro de la estructura como un índice (index).

☕ Implementación en Java

Recuerda: En programación los índices comienzan en 0 (representando $v_1$ en matemáticas).

public class GestionVectores {
    public static void main(String[] args) {
        // v = [10.5, 20.0, -5.3]
        double[] vectorPosicion = {10.5, 20.0, -5.3};
        
        // Acceso: índice 0 equivale al subíndice v1 en matemáticas
        System.out.println("Componente X (Índice 0): " + vectorPosicion[0]);
        
        // La propiedad .length nos da la dimensión n
        int dimension = vectorPosicion.length;
        System.out.println("El vector es de dimensión: " + dimension);
    }
}

Una matriz es un arreglo rectangular de números organizados en $m$ filas y $n$ columnas. El tamaño de la matriz se denomina orden y se escribe como $m \times n$.

Un elemento genérico se identifica como $a_{ij}$ ($i$ = fila, $j$ = columna):

$$A = \begin{bmatrix} a_{11} & a_{12} & \dots & a_{1n} \\ a_{21} & a_{22} & \dots & a_{2n} \\ \vdots & \vdots & \ddots & \vdots \\ a_{m1} & a_{m2} & \dots & a_{mn} \end{bmatrix}$$

☕ Implementación en Java

En Java, una matriz es un "arreglo de arreglos" (bidimensional).

public class GestionMatrices {
    public static void main(String[] args) {
        // Definición de una matriz de orden 2x3
        double[][] matrizDatos = {
            {1.2, 3.4, 5.6}, // Fila 0 (Java) - Fila 1 (Matemáticas)
            {7.8, 9.0, 2.1}  // Fila 1 (Java) - Fila 2 (Matemáticas)
        };

        // Acceder a a21 (Fila 2, Col 1) -> en Java es [1][0]
        double elemento = matrizDatos[1][0];
        System.out.println("Elemento en fila 2, columna 1: " + elemento);
    }
}
