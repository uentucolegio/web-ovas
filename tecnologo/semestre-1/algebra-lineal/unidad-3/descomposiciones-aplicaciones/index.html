Descomposiciones y aplicaciones del álgebra lineal

Una descomposición matricial expresa una matriz como producto de matrices con estructura especial. En lugar de operar directamente con una matriz grande, podemos resolver el problema mediante pasos más simples, estables y eficientes.

Las factorizaciones LU y QR ayudan a resolver sistemas de ecuaciones y problemas de mínimos cuadrados. La descomposición en valores singulares (SVD) permite comprimir imágenes, reducir dimensiones y descubrir patrones en conjuntos de datos.

Matriz → factores

Una matriz A se representa como el producto de matrices más sencillas, por ejemplo A = LU o A = QR.

Aplicaciones en software

  • • Comprimir imágenes y reducir almacenamiento.

¿Qué es una descomposición?

Factorizar una matriz consiste en escribirla como un producto de matrices con propiedades convenientes. La elección depende del problema: triangularidad para resolver sistemas, ortogonalidad para aproximar datos o valores singulares para analizar estructura y compresión.

LU

A = LU: una matriz triangular inferior L y otra triangular superior U. Conviene para resolver varios sistemas con la misma matriz A.

Ax = b → Ly = b, Ux = y

QR

A = QR: Q tiene columnas ortonormales y R es triangular superior. Es una herramienta estable para mínimos cuadrados.

AᵀA x = Aᵀb

SVD

A = UΣVᵀ: U y V son ortogonales y Σ contiene valores singulares no negativos.

A = UΣVᵀ

¿Por qué factorizar?

Una buena factorización reutiliza cálculos, reduce el costo de operaciones repetidas y ayuda a controlar errores numéricos. En la práctica se usan bibliotecas optimizadas en vez de implementar los algoritmos desde cero.

Factorización LU

La factorización LU separa la eliminación gaussiana en dos etapas. L guarda los multiplicadores usados para eliminar entradas y U es la matriz triangular resultante. Si se requiere, se intercambian filas mediante una matriz de permutación P: PA = LU.

A = LU

Resolver Ax = b equivale a resolver primero Ly = b y luego Ux = y.

Para A = [2 1; 4 3], eliminamos el 4 debajo del pivote 2 usando el multiplicador m₂₁ = 4/2 = 2.

L = [1 0; 2 1]   U = [2 1; 0 1]

Se verifica que LU = [2 1; 4 3] = A. Para matrices generales puede ser necesario pivotear filas.

Factorización QR y mínimos cuadrados

En A = QR, las columnas de Q son vectores ortonormales y R es triangular superior. Cuando hay más ecuaciones que incógnitas, QR permite encontrar la solución que minimiza el error ||Ax − b||₂, como ocurre al ajustar una recta a mediciones.

Ortonormalidad

QᵀQ = I: las columnas de Q tienen longitud 1 y son perpendiculares entre sí. Esto reduce la amplificación de errores en los cálculos.

Ajuste de datos

En el modelo Ax ≈ b, la solución de mínimos cuadrados aproxima los datos cuando las ecuaciones no tienen una solución exacta común.

Con mediciones (1, 2), (2, 2.9) y (3, 4.2), el sistema para ajustar y = c + mx suele estar sobredeterminado. QR encuentra c y m minimizando la suma de los cuadrados de los residuos.

La solución no tiene que pasar exactamente por cada medición; busca el mejor ajuste global.

Nota numérica: para mínimos cuadrados suele preferirse QR frente a formar AᵀA, porque esta última operación puede empeorar el condicionamiento del problema.

Descomposición en valores singulares (SVD)

Toda matriz real A de tamaño m × n puede expresarse como A = UΣVᵀ. Las columnas de U y V son vectores ortonormales y los valores de Σ, llamados valores singulares, se ordenan de mayor a menor.

A = UΣVᵀ

Vᵀ orienta los datos • Σ escala cada dirección • U los expresa en el espacio de salida

Rango

El número de valores singulares distintos de cero indica el rango de A.

Aproximación

Conservar los valores singulares más grandes produce una aproximación de menor rango.

Interpretación

Cada valor singular mide cuánto se amplía una dirección principal.

Una imagen en escala de grises puede modelarse como una matriz. Su aproximación de rango k conserva solo los k valores singulares mayores.

Menos componentes → menos datos que almacenar, con una pérdida gradual de detalle.

SVD también se usa en reducción de dimensionalidad, búsqueda y recomendación de contenidos.

Aplicaciones en desarrollo de software

Las descomposiciones conectan las ideas del álgebra lineal con tareas concretas de cómputo. En aplicaciones reales, las bibliotecas numéricas eligen algoritmos según el tamaño, la forma y las propiedades de los datos.

Gráficos y visión por computador

Las matrices representan transformaciones de coordenadas; la SVD ayuda a estimar rango, detectar patrones y procesar señales e imágenes.

Ciencia de datos y aprendizaje automático

La SVD sustenta métodos de reducción de dimensionalidad y factorización de datos. QR y LU aparecen en el ajuste de modelos y la resolución de sistemas internos.

Simulación y optimización

Resolver sistemas lineales de forma eficiente permite simular redes, estructuras, circuitos y procesos físicos con muchas variables.

Criterio de implementación: utiliza funciones de bibliotecas como NumPy o SciPy, revisa la forma y el tipo de los datos, y evita calcular explícitamente la inversa de una matriz para resolver Ax = b.
