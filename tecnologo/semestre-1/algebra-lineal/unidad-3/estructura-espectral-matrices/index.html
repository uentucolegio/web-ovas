Estructura espectral de matrices

La estructura espectral de una matriz está formada por sus valores propios, vectores propios y espacios propios. Estos elementos revelan las direcciones que una transformación conserva y los factores con los que las amplía, contrae o invierte.

Analizar el espectro permite comprender sistemas dinámicos, simplificar potencias de matrices y resolver problemas de procesamiento de datos, gráficos, aprendizaje automático y simulación.

Matriz → Espectro

El polinomio característico permite encontrar los valores propios; cada valor propio determina uno o varios vectores propios.

Aplicaciones en software

  • • Compresión y reducción de dimensionalidad.
  • • Análisis de estabilidad de sistemas.
  • • Ranking, gráficos, visión artificial y ciencia de datos.

  • 📐 Aplicar el criterio de diagonalización para determinar si una matriz puede escribirse como PDP⁻¹.

Valores propios

Un número λ es un valor propio de una matriz cuadrada A si existe un vector no nulo v que cumple Av = λv. Al aplicar A, el vector conserva su dirección y solo cambia su escala u orientación.

Ecuación fundamental

El vector v debe ser diferente del vector cero.

Av = λv

Interpretación

Si λ > 1, la dirección se amplía; si 0 < λ < 1, se contrae; si λ < 0, además invierte su orientación; y si λ = 0, colapsa al origen.

Caso inmediato

En una matriz triangular, los valores propios son los elementos de su diagonal. Para A = [ 3 1; 0 −2 ], el espectro es {3, −2}.

Vectores y espacios propios

Para cada valor propio λ, los vectores propios se obtienen resolviendo un sistema homogéneo.

(A − λI)v = 0

El espacio propio Eλ es el núcleo de A − λI y contiene el vector cero y todos los vectores propios asociados a λ.

Para A = [ 4 1; 2 3 ] y λ = 5 resolvemos:

(A − 5I)v = [ −1 1; 2 −2 ]v = 0

La relación −x + y = 0 implica y = x. Por tanto, los vectores propios son los múltiplos no nulos de (1, 1).

E5 = span{(1, 1)}

Independencia

Vectores propios asociados a valores propios distintos son linealmente independientes.

Multiplicidad

La multiplicidad geométrica es la dimensión del espacio propio y nunca supera la multiplicidad algebraica.

Polinomio característico

Los valores propios son las raíces del polinomio característico. Para una matriz 2 × 2 puede construirse usando su traza y su determinante.

p(λ) = det(A − λI) = λ² − tr(A)λ + det(A)

tr(A) = a + d   •   det(A) = ad − bc   •   A = [ a b; c d ]

Suma espectral

La suma de los valores propios, contando multiplicidades, es igual a la traza de A.

Producto espectral

El producto de los valores propios, contando multiplicidades, es igual al determinante de A.

Diagonalización y descomposición espectral

Una matriz A es diagonalizable si posee una base completa de vectores propios. En ese caso puede escribirse mediante una matriz diagonal D.

A = PDP−1

P contiene los vectores propios como columnas • D contiene los valores propios correspondientes en su diagonal

Para A = [ 4 1; 2 3 ] se obtienen λ₁ = 5 con v₁ = (1, 1), y λ₂ = 2 con v₂ = (1, −2).

P = [ 1 1; 1 −2 ]   y   D = [ 5 0; 0 2 ]

Como los dos vectores propios son independientes, P es invertible y A = PDP−1.

La diagonalización simplifica potencias y funciones de matrices:

Ak = PDkP−1

Elevar D a una potencia solo requiere elevar sus elementos diagonales. Esto acelera cálculos en simulaciones, recurrencias y sistemas dinámicos.

Criterio útil: una matriz n × n con n valores propios distintos siempre es diagonalizable. Una matriz real simétrica admite una diagonalización ortogonal.
