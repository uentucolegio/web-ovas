Transformaciones lineales y su representación matricial

Una transformación lineal es una función que actúa sobre vectores y conserva las operaciones fundamentales del espacio: la suma de vectores y la multiplicación por escalares. En desarrollo de software aparece al rotar elementos gráficos, escalar imágenes, transformar coordenadas o procesar datos multidimensionales.

Cada transformación lineal entre espacios de dimensión finita puede representarse mediante una matriz. Así, una regla abstracta se convierte en una operación concreta y programable: multiplicar una matriz por un vector.

Función → Matriz

La matriz reúne en sus columnas las imágenes de los vectores de la base canónica. Con ella calculamos la imagen de cualquier vector.

Aplicaciones en software

  • • Transformaciones de objetos en gráficos 2D y 3D.
  • • Conversión de coordenadas y procesamiento de imágenes.
  • • Robótica, simulación y análisis de datos.

Objetivos de aprendizaje

  • ↗️ Verificar si una función es una transformación lineal comprobando las propiedades de aditividad y homogeneidad.
  • 🔢 Construir la matriz asociada a una transformación lineal a partir de las imágenes de los vectores de la base canónica.
  • 🔄 Identificar el efecto geométrico de una matriz (escalamiento, rotación, reflexión, cizallamiento) sobre figuras del plano.
  • 📐 Calcular el determinante de una matriz 2×2 e interpretar su relación con el área, la orientación y la invertibilidad de la transformación.

¿Qué hace lineal a una transformación?

Una función T: ℝⁿ → ℝᵐ es lineal cuando conserva combinaciones lineales. Para todos los vectores u, v y todo escalar λ debe cumplir las siguientes propiedades.

Aditividad

Transformar una suma equivale a sumar las imágenes.

T(u + v) = T(u) + T(v)

Homogeneidad

Un escalar puede entrar o salir de la transformación.

T(λv) = λT(v)

Prueba rápida

Toda transformación lineal cumple T(0) = 0. Por eso T(x, y) = (x + 2, y) no es lineal: desplaza el origen hasta (2, 0).

Representación matricial

En ℝ² usamos la base canónica e₁ = (1, 0) y e₂ = (0, 1). La primera columna de la matriz es T(e₁) y la segunda es T(e₂).

A = [ T(e₁)   T(e₂) ]    y    T(v) = Av

abcd · (x, y) = (ax + by, cx + dy)

Sea T(x, y) = (2x − y, x + 3y). Evaluamos los vectores de la base:

  • T(e₁) = T(1, 0) = (2, 1)
  • T(e₂) = T(0, 1) = (−1, 3)

Organizamos estas imágenes como columnas:

A = [ 2   −1;   1   3 ]

Transformaciones geométricas en ℝ²

La forma de la matriz determina el efecto sobre los vectores y las figuras del plano.

Escalamiento

A = [ sₓ 0; 0 sᵧ ] amplía o contrae los ejes de forma independiente. Con A = [ 2 0; 0 3 ], el vector (x, y) pasa a (2x, 3y).

Rotación

A = [ cosθ −sinθ; sinθ cosθ ] gira los vectores un ángulo θ alrededor del origen sin cambiar sus longitudes.

Reflexión

A = [ 1 0; 0 −1 ] refleja respecto al eje x: cada punto (x, y) se convierte en (x, −y).

Cizallamiento

A = [ 1 k; 0 1 ] inclina horizontalmente una figura y conserva el paralelismo de sus lados.

Propiedades comunes: el origen permanece fijo, las líneas se transforman en líneas o puntos y las rectas paralelas conservan su paralelismo.

Determinante y composición

Para A = [ a b; c d ], el determinante resume cómo cambia el área y permite saber si la transformación tiene inversa.

det(A) = ad − bc

|det(A)|: factor de cambio del área • det(A) < 0: invierte la orientación • det(A) = 0: no existe inversa

Para A = [ 2 −1; 1 3 ]:

det(A) = (2)(3) − (−1)(1) = 7

La transformación multiplica las áreas por 7, conserva la orientación y es invertible.

Si primero aplicamos T, representada por A, y luego S, representada por B, obtenemos:

(S ∘ T)(v) = B(Av) = (BA)v

El orden importa: en general, BA ≠ AB.
