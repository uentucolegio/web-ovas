Clasificación de Sistemas

No todos los sistemas tienen solución. En programación, detectar esto evita bucles infinitos o errores de división por cero.

Compatible Determinado

Las líneas se cruzan en un único punto. Hay una solución exacta.

Compatible Indeterminado

Las líneas son la misma. Existen infinitas soluciones.

Incompatible

Las líneas son paralelas. No existe solución común.

Regla de Cramer: El Enfoque Computacional

Es el método preferido para automatizar soluciones mediante el uso de determinantes.

SISTEMA $2 \times 2$

$$\begin{cases} a_1x + b_1y = c_1 \\ a_2x + b_2y = c_2 \end{cases}$$
$$x = \frac{\Delta x}{\Delta}$$
$$y = \frac{\Delta y}{\Delta}$$

Condición: El determinante principal $\Delta$ debe ser $\neq 0$.

Algoritmo de Cramer

Este código implementa el cálculo de determinantes para resolver un sistema de forma determinística:

public class SistemaCramer {
    public static void main(String[] args) {
        // Ecuaciones: a1x + b1y = c1 | a2x + b2y = c2
        double a1 = 2, b1 = 3, c1 = 8;
        double a2 = 1, b2 = -1, c2 = -1;

        // Calculamos determinantes
        double detPrincipal = (a1 * b2) - (a2 * b1);
        double detX = (c1 * b2) - (c2 * b1);
        double detY = (a1 * c2) - (a2 * c1);

        if (detPrincipal != 0) {
            double x = detX / detPrincipal;
            double y = detY / detPrincipal;
            System.out.println("Solución: x=" + x + ", y=" + y);
        } else {
            System.out.println("El sistema no tiene solución única.");
        }
    }
}
