Estructura secuencial y condicional

En programación, resolver un problema no empieza escribiendo código, sino pensando de forma ordenada. La lógica de programación te ayuda a convertir una necesidad (por ejemplo, calcular un total, validar un dato o tomar una decisión) en una secuencia de pasos claros y verificables. En esta guía trabajarás dos estructuras básicas que aparecen en casi cualquier algoritmo: la estructura secuencial, donde las instrucciones se ejecutan en el mismo orden en que se escriben, y la estructura condicional, donde el algoritmo puede tomar caminos distintos según se cumpla o no una condición.

  • ✓ Reconocer las diferencias entre una estructura secuencial y una estructura condicional en la solución de problemas.
  • ✓ Diseñar algoritmos en pseudocódigo usando instrucciones secuenciales y condicionales (Si-Entonces, Si-Entonces-Sino y decisiones anidadas).
  • ✓ Validar la lógica de un algoritmo mediante casos de prueba, identificando errores comunes en condiciones y comparaciones.

Estructura secuencial

En una estructura secuencial, las instrucciones se ejecutan una tras otra, sin saltos ni decisiones. Es la forma más directa de describir un procedimiento: primero se obtiene información, luego se realizan operaciones y finalmente se presenta un resultado.

Características principales

  • ✓ El orden importa: cambiar el orden de los pasos puede cambiar el resultado.
  • ✓ No hay bifurcaciones: siempre se sigue el mismo camino.
  • ✓ Es ideal para cálculos directos, conversiones y procedimientos lineales.

Ejemplo 1: Total a pagar con IVA.

Situación: una tienda necesita calcular el total a pagar a partir del valor de una compra y un IVA del 19%.

Proceso CalcularTotalIVA

text 
    Definir compra, iva, total Como Real

    Escribir "Ingrese el valor de la compra:"

    Leer compra

    iva <- compra * 0.19

    total <- compra + iva

    Escribir "IVA: ", iva

    Escribir "Total a pagar: ", total

FinProceso

Caso de prueba rápido:

Si compra = 100000, entonces IVA = 19000 y total = 119000.

Ejemplo 2: Convertir minutos a horas y minutos (secuencial)

Situación: a partir de un número de minutos, se desea expresar el tiempo en horas y minutos.

Proceso ConvertirMinutos

text 
    Definir minutos, horas, resto Como Entero

    Escribir "Ingrese los minutos:"

    Leer minutos

    horas <- trunc(minutos / 60)

    resto <- minutos % 60

    Escribir "Horas: ", horas

    Escribir "Minutos: ", resto

FinProceso

Estructura condicional

La estructura condicional permite que el algoritmo decida qué hacer según una condición lógica (Verdadero/Falso). Con esto se pueden crear reglas: si se cumple algo, se ejecuta un bloque de instrucciones; si no, se ejecuta otro o se continúa.

Operadores y condicionales
1. Operadores que suelen usarse en condiciones: ▼
Relacionales: =, <>, <, >, <=, >= Lógicos: Y (AND), O (OR), NO (NOT)
2. Condicional simple (Si-Entonces) ▼
Se usa cuando solo hay una acción que ocurre si la condición se cumple. Si (edad >= 18) Entonces Escribir "Eres mayor de edad" FinSi
3. Condicional doble (Si-Entonces-Sino) ▼
Se usa cuando hay dos caminos: uno si se cumple la condición y otro si no se cumple. Si (numero % 2 = 0) Entonces Escribir "El número es par" Sino Escribir "El número es impar" FinSi
4. Condicionales múltiples y anidadas ▼
Cuando hay más de dos posibilidades, se pueden encadenar condiciones (Sino Si) o anidar (un Si dentro de otro). La clave es mantener la lectura clara e indentada.

Ejemplo 3: Clasificación de una nota (0.0 a 5.0)

Situación: clasificar el desempeño según el valor de la nota.

Proceso ClasificarNota

text 
    Definir nota Como Real
    Escribir "Ingrese la nota (0.0 a 5.0):"
    Leer nota
    Si (nota < 0 O nota > 5) Entonces
        Escribir "Nota inválida"
    Sino Si (nota >= 4.0) Entonces
        Escribir "Alto"
    Sino Si (nota >= 3.0) Entonces
        Escribir "Básico"
    Sino
        Escribir "Bajo"
    FinSi
FinProceso

Buenas prácticas al usar condicionales:

  • ✓ Escribe condiciones simples y evita mezclar muchas comparaciones en una sola línea sin necesidad.
  • ✓ Revisa rangos: define claramente si el límite es inclusivo (>=, <=) o exclusivo (<, >).
  • ✓ Prueba al menos tres casos: uno que cumpla la condición, otro que no la cumpla y un caso límite (por ejemplo, el valor exacto del límite).
