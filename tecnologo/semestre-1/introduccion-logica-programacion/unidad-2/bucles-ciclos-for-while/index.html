Introducción

En programación, muchos problemas requieren ejecutar una misma acción varias veces. Desde contar números hasta procesar listas de datos, la repetición es fundamental.

Los bucles for y while permiten automatizar tareas repetitivas, reducir código innecesario y mejorar la eficiencia de los algoritmos.

Objetivos de aprendizaje

  • ✓ Comprender y aplicar estructuras repetitivas en lógica algorítmica usando for y while.
  • ✓ Diferenciar cuándo usar ciclos definidos (for) y ciclos condicionados (while).
  • ✓ Resolver problemas de repetición de forma lógica, eficiente y estructurada.

Contenido

Piensa en una tarea que hayas repetido varias veces en programación: mostrar datos, validar entradas o recorrer una lista.

Responde en tu cuaderno: ¿cuántas veces se repite? ¿la cantidad es fija o depende de una condición?

¿Qué es un ciclo o bucle?

Un ciclo es una estructura de control que repite un conjunto de instrucciones varias veces.

Idea clave: "haz esto varias veces sin escribirlo repetidamente".

Ciclo FOR

Se usa cuando sabemos cuántas veces se repite una acción.

pseudocódigo 
Para (inicio; condición; incremento) hacer
    instrucciones
FinPara

Ciclo WHILE

Se usa cuando no sabemos exactamente cuántas repeticiones habrá. El ciclo continúa mientras la condición sea verdadera.

pseudocódigo 
Mientras (condición) hacer
    instrucciones
FinMientras

Diferencias entre FOR y WHILE

Ejemplos rápidos

pseudocódigo 
Para i = 1 hasta 5 hacer
    Escribir i
FinPara

sum = 0
Leer num
Mientras num != 0 hacer
    sum = sum + num
    Leer num
FinMientras
Escribir sum

¿Cuándo usar FOR y cuándo usar WHILE?

  • ✓ FOR: cuando conoces la cantidad de repeticiones (ejemplo: recorrer 10 elementos).
  • ✓ WHILE: cuando repites hasta que una condición cambie (ejemplo: leer datos hasta ingresar 0).

Errores comunes en bucles

Haz clic en cada error para ver la forma correcta de solucionarlo:

Debes actualizar la variable en cada iteración (ejemplo: i = i + 1).
Verifica límites (<, <=, >) para no perder iteraciones ni pasarte.
Inicializa antes del ciclo (ejemplo: suma = 0, contador = 0).
Asegura una salida real: condición alcanzable y actualización de estado.

Mini reto: ¿qué causa un bucle infinito más frecuentemente?

Cómo evitar bucles infinitos

pseudocódigo 
i = 1
Mientras i <= 5 hacer
    Escribir i
    i = i + 1   // actualizar siempre la variable de control
FinMientras

Trazado rápido (dry run)

Antes de ejecutar, simula 2 o 3 vueltas del ciclo en papel:

1) valor inicial, 2) evaluación de condición, 3) salida de cada iteración, 4) valor final.

Este método te ayuda a detectar errores de lógica antes de programar.

Actividad 1 · Pensamiento lógico

Pendiente

Escribe pseudocódigo para: 1) imprimir números del 1 al 10, 2) mostrar pares del 1 al 20 y 3) contar regresivamente de 10 a 1.

Pista para esta actividad
Incluye estructura de inicio, ciclo y salida. Puedes usar: para i=1 hasta 10, condición para pares y una cuenta regresiva desde 10 hasta 1.

Actividad 2 · Aplicación

Pendiente

Diseña un algoritmo que solicite un número y repita “Aprendiendo programación” esa cantidad de veces.

Pista para esta actividad
Debes mostrar que recibes un dato de entrada (leer n) y que repites un mensaje dentro del ciclo exactamente n veces.

Actividad 3 · Reto

Pendiente

Crea un algoritmo que pida números al usuario, repita hasta que ingrese 0 y muestre la suma total.

Pista para esta actividad
Necesitas una variable acumuladora, un ciclo mientras y una condición clara de parada cuando el dato ingresado sea 0.
