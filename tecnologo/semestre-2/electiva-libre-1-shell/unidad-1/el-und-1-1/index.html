Terminal, shell y estructura general de GNU/Linux

Gran parte de la infraestructura digital que sostiene internet funciona sobre GNU/Linux, el sistema operativo utilizado por empresas como Google, Netflix y Amazon debido a su velocidad, estabilidad y seguridad, sin depender de interfaces gráficas para operar. Este contenido te permite dar un paso más allá del uso cotidiano del mouse para adentrarte en el rol de desarrollador: aquí aprenderás a interactuar directamente con el sistema a través de la Terminal, utilizando comandos.

✨ Pasarás de hacer clic con el mouse a escribir comandos como un verdadero desarrollador: descubre el Kernel, las herramientas GNU y el sistema de archivos de Linux. 🐧💻⌨️

💻 ¿Qué es un Sistema Operativo?

🎻
Imagínalo así:

Un sistema operativo es como el director de una orquesta: no toca cada instrumento (el hardware) directamente, pero coordina que la memoria, el procesador y los dispositivos trabajen juntos sin caos.
Es el software que administra los recursos físicos del computador y sirve de intermediario entre el usuario y el hardware.

👉 Sus funciones principales son:

Administración de memoria
Gestión del procesador
Manejo de archivos
Control de dispositivos
Gestión de usuarios
Seguridad
💻 Sistema Operativo 💡 Ejemplo de uso
Windows Equipos de escritorio y oficina
macOS Computadores Apple
GNU/Linux Servidores, desarrollo y educación
Android Dispositivos móviles
iOS Móviles y tablets Apple
📌 El sistema operativo es el puente entre tú y el hardware de tu computador. Sin él, no podríamos ejecutar ningún programa.

🐧 ¿Qué es GNU/Linux?

El término "Linux" corresponde propiamente al núcleo o kernel del sistema; para referirse al sistema operativo completo, la denominación correcta es GNU/Linux.

🚗
Imagínalo así:

Linux (el Kernel) es como el motor de un auto: mueve todo, pero no puedes conducir solo con el motor. GNU son el volante, los asientos y el tablero: las herramientas que te permiten usar ese motor. Juntos forman el auto completo: GNU/Linux.

🛠️

GNU

Conjunto de herramientas del proyecto GNU que permiten al usuario trabajar con el sistema.

Bash gcc ls cp mv cat grep
🐧

Linux (el Kernel)

El núcleo del sistema operativo. Sus responsabilidades incluyen administrar memoria, controlar dispositivos, administrar procesos y comunicarse con el hardware.

Componente ¿Qué es? Ejemplo
GNU Software libre con herramientas y utilidades para usar el sistema Bash, GCC, GNU Coreutils
Linux El núcleo (kernel) que administra el hardware y los recursos Kernel usado en Ubuntu, Debian o Fedora
GNU/Linux Sistema operativo completo: kernel Linux + herramientas GNU Ubuntu, Linux Mint, Debian
📌 Cuando decimos "Linux" a secas, normalmente nos referimos a GNU/Linux, el sistema operativo completo.

📦 ¿Qué es una distribución Linux?

Una distribución (Distro) es un sistema operativo construido alrededor del Kernel Linux junto con diferentes herramientas GNU. Cada distribución tiene objetivos diferentes:

📦 Distribución 🎯 Uso principal
Ubuntu Educación y escritorio
Debian Servidores
Fedora Desarrollo
Arch Linux Usuarios avanzados
Kali Linux Seguridad informática
Rocky Linux Servidores empresariales
💡 Regla: No hay una distribución "mejor": elige la que se ajuste al objetivo de tu proyecto (educación, servidor, desarrollo o seguridad).

⌨️ Terminal y Shell

🖥️
Imagínalo así:

En lugar de utilizar botones y ventanas, en la Terminal le escribes instrucciones directamente al sistema. Por ejemplo, al escribir ls el sistema responde mostrando el contenido del directorio actual.

🐚 ¿Qué es el Shell?

El Shell es el intérprete de comandos: su función consiste en traducir lo que escribe el usuario para que el Kernel pueda ejecutarlo. Haz clic en cada tarjeta para conocer los shells más usados:

🐚 Bash
❓ Bourne Again Shell: el shell más utilizado actualmente
🐚 zsh
❓ Muy personalizable, usado por defecto en macOS
🐚 fish
❓ Amigable, con autocompletado inteligente
🐚 sh
❓ Shell POSIX básico, base de muchos scripts
🐚 ksh
❓ Korn Shell, usado en entornos Unix clásicos
💡 La Terminal te permite reducir la dependencia de interfaces gráficas al interactuar directamente con el sistema operativo.

🧭 ¿Cómo funciona un comando?

👉 Todo comando posee una estructura similar:

comando opciones argumentos

Ejemplo: ls -l Documentos. Haz clic en cada fila para identificar cada parte:

🧩 Parte del comando 💡 En el ejemplo "ls -l Documentos"
comando ls
opción -l
argumento Documentos
📌 Las opciones modifican el comportamiento del comando y los argumentos indican sobre qué elemento actuar.

🗂️ Estructura del sistema de archivos y rutas

A diferencia de Windows, donde existen unidades como C: o D:, en GNU/Linux todo parte de un único directorio raíz, representado por /. Todos los archivos, carpetas y dispositivos se organizan bajo este directorio formando una estructura en árbol: 

/
├── bin
├── boot
├── dev
├── etc
├── home
│   ├── estudiante
│   └── profesor
├── lib
├── media
├── opt
├── proc
├── root
├── tmp
├── usr
└── var
📍

Ruta absoluta

Comienza desde la raíz / y especifica el recorrido completo.

/home/estudiante/Documentos/proyecto

📍 No depende de dónde estés
VS
🔄

Ruta relativa

Parte desde el directorio actual en el que te encuentres.

Documentos/proyecto

🔄 Depende de tu ubicación actual
📌 El comando cd permite la navegación entre directorios en la terminal: su función principal es cambiar la ubicación actual desde la que estamos trabajando.
