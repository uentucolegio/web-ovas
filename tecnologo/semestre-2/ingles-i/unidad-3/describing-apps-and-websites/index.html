📱 Describing apps and websites: your first tech pitch in English

Piensa en las aplicaciones que abriste hoy: una app de mensajería, el navegador, la plataforma de la universidad… Ahora imagina que debes explicarle a alguien, en inglés y en pocas frases, qué es cada una y para qué sirve. Eso es exactamente lo que hacen a diario los desarrolladores de software: describen sus productos en tiendas de aplicaciones, páginas web, documentación y presentaciones de proyectos.

En este OVA de la Unidad 3 aprenderás a construir descripciones cortas de aplicaciones y sitios web usando tres estructuras muy simples — It is a…, It has… y You can use it to… — junto con adjetivos útiles como free, fast, easy to use, secure y popular, todo en presente simple. Estas mismas frases aparecen en Google Play, en la App Store y en los README de GitHub, así que también te ayudarán a entender lo que lees allí. Además, son la base de la evidencia del curso: la presentación corta de una aplicación.

✨ Learning Tip: Three short sentences are enough to describe any app: what it is, what it has, and what you can do with it. Master this formula and you can talk about any software product. 🚀

Objetivos de aprendizaje

  • 🧩 Identificar las estructuras básicas It is a…, It has… y You can use it to… en descripciones cortas de aplicaciones y sitios web escritas en presente simple.
  • ⭐ Emplear adjetivos útiles del inglés técnico (free, fast, easy to use, secure, popular, useful) para caracterizar herramientas de software.
  • 📖 Comprender descripciones breves de aplicaciones como las que aparecen en tiendas de aplicaciones, sitios web y documentación de software.
  • 🗣️ Construir una descripción corta y coherente de una aplicación, como preparación para la evidencia del curso "Presentación corta de una aplicación".

🎮 Misión de exploración: recorre las 3 estaciones, descubre las tarjetas y responde los mini retos

⭐ Puntos: 0

Toda descripción corta de una app o de un sitio web responde tres preguntas. Cada pregunta tiene su propia estructura en presente simple:

❓ What is it?

It is a…

Dice qué es: el tipo de aplicación o sitio web.

It is a free messaging app.

It is a website for online courses.

❓ What does it have?

It has…

Dice qué tiene: sus características (features).

It has a simple interface.

It has group chats and video calls.

❓ What does it do? / What is it for?

You can use it to…

Dice para qué sirve: la acción va en verbo base.

You can use it to send messages.

You can use it to learn English online.

Para hablar de las personas que la usan, agrega una frase con presente simple. Recuerda la -s de la tercera persona singular:

Who uses it? → Millions of people use it every day.

My teacher uses it in class. (he/she/it → verbo + s)

The app works on Android and iOS.

🎯 Mini reto (+5 pts)

Which sentence tells us what you DO with the app (its purpose)?

Los adjetivos hacen tu descripción más interesante y precisa. En inglés, el adjetivo no cambia con el plural y suele ir antes del sustantivo (a fast browser) o después del verbo to be (the browser is fast).

🎯 Mini reto (+5 pts)

Which adjective describes an app that protects your data and passwords?

Lee esta descripción corta de Visual Studio Code, un editor de código que probablemente usarás durante toda tu carrera. Es el mismo estilo de texto que encuentras en una tienda de aplicaciones o en la página oficial de una herramienta:

"Visual Studio Code is a free code editor. It has a simple interface and thousands of extensions. You can use it to write, edit and debug code. It is fast, easy to use and very popular. Millions of developers use it every day."

🏗️ Misión 2: Build your description

Ahora construye tú una descripción completa. Primero elige la app que quieres describir; luego selecciona una frase de cada bloque (It is… → It has… → You can…). Cuidado: algunas frases pertenecen a otras apps. Al final pulsa Check my description para verificar la estructura y el contenido.

1️⃣ Choose your app:

3️⃣ It has… (what does it have?)

4️⃣ You can… (what is it for?)
