Las interfaces, los instaladores, los tutoriales y la documentación técnica te hablan casi siempre en la misma forma gramatical del inglés: el imperative. Es el idioma de las órdenes y las instrucciones, y por eso es el primer inglés que necesita dominar cualquier persona que desarrolla software.

En este OVA aprenderás cómo se construye el imperativo afirmativo (Open the file) y negativo (Don't delete the folder), conocerás los verbos de acción más frecuentes de las interfaces (click, type, select, drag, save, install...) y practicarás secuencias de instrucciones con first, then, next y finally, como las que encuentras al instalar una aplicación. Todo con misiones, puntos e insignias para que avances jugando.

✨ Al final de este OVA podrás leer, seguir y escribir instrucciones básicas en inglés como las de cualquier instalador o tutorial de software. 🚀

Objetivos de aprendizaje

  • 🧠 Identificar la estructura del imperativo afirmativo y negativo en inglés (Open the terminal / Don't close the window) en mensajes de interfaces, instaladores y documentación de software.
  • 💡 Reconocer los verbos de acción más frecuentes de las interfaces digitales (click, type, select, drag, save, install, download, restart) y relacionarlos con la tarea que indican.
  • 🔧 Comprender secuencias de instrucciones ordenadas con first, then, next y finally para seguir correctamente tutoriales y procesos de instalación en inglés.
  • 📦 Producir instrucciones breves en inglés usando el imperativo, aplicándolas a tareas iniciales del desarrollo de software como instalar herramientas o usar una interfaz.

El imperative es la forma más simple del inglés: se usa el verbo en su forma base, sin sujeto. No decimos "You open the file", decimos simplemente "Open the file". Para dar una orden negativa (lo que NO debes hacer), se agrega Don't (o Do not, más formal) antes del verbo. Y si quieres sonar más amable, agrega please.

Tipo Estructura Ejemplo en software Significado
Afirmativo ✅ Verbo base + complemento Open the terminal. Abre la terminal.
Afirmativo ✅ Verbo base + complemento Save your changes. Guarda tus cambios.
Negativo 🚫 Don't + verbo base Don't close the window. No cierres la ventana.
Negativo 🚫 Do not + verbo base Do not delete the folder. No elimines la carpeta.
Cortés 🙏 Please + verbo base Please restart your computer. Por favor, reinicia tu computador.

Fíjate en un detalle clave: en el imperativo el verbo nunca cambia. No lleva -s, ni -ing, ni to. Por eso los botones y mensajes de las aplicaciones son tan cortos y directos: Install, Download, Accept, Cancel, Try again.

Una instrucción sola no basta: instalar un programa o configurar una herramienta requiere varios pasos en orden. Para marcar ese orden, el inglés técnico usa palabras de secuencia: First (primero), Then (luego), Next (después), After that (después de eso) y Finally (finalmente).

💻 Mini tutorial: How to install Visual Studio Code

  1. First, download the installer from the official website.
  2. Then, open the file and accept the license agreement.
  3. Next, choose the installation folder.
  4. After that, click "Install" and wait a few seconds.
  5. Finally, open Visual Studio Code and start coding! 🎉

Observa que cada paso combina lo que ya sabes: una palabra de secuencia + un imperativo + un objeto (Then, open the file). Esa es exactamente la fórmula de los tutoriales, los README y las guías de instalación que leerás durante toda tu carrera.
