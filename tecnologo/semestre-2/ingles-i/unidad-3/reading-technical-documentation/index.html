🔎 Don't read everything — read smart

Casi toda la documentación del mundo del software está escrita en inglés: el README de una librería, la página de ayuda de un editor de código, la guía de instalación de una herramienta. Cuando un desarrollador principiante abre uno de esos documentos, su primer impulso suele ser traducir palabra por palabra… y ahí es donde se pierde: el texto parece enorme, lento y lleno de términos desconocidos.

La buena noticia es que la documentación técnica no se lee como una novela. Tiene una estructura predecible (title, requirements, steps, examples, notes, warnings) y existen estrategias de lectura — skimming, scanning, uso de cognados y palabras clave — que te permiten encontrar exactamente lo que necesitas en segundos, aunque no conozcas todas las palabras. En este OVA vas a entrenar esas estrategias leyendo fragmentos reales de un README y de páginas de ayuda sencillas.

✨ Reading documentation strategically — not word by word — is a beginner developer's superpower. 🦸

Objetivos de aprendizaje

  • 🔍 Aplicar las estrategias de lectura skimming y scanning para comprender mensajes breves en inglés relacionados con herramientas, comandos e interfaces de desarrollo de software.
  • 🧩 Reconocer cognados, falsos amigos y palabras clave frecuentes de la documentación técnica (requirements, install, usage, example, note, warning, error).
  • 📄 Identificar la estructura típica de un README o página de ayuda en inglés: título, requisitos, pasos, ejemplos y advertencias.
  • 🎯 Interpretar un fragmento sencillo de documentación en inglés para extraer datos específicos (versiones, comandos, archivos) sin leerlo palabra por palabra.

Imagina que abres la página de instalación de una herramienta. Tienes dos preguntas posibles: "¿De qué trata esta página?" y "¿Qué versión de Python necesito?". Cada pregunta se responde con una estrategia distinta:

🛩️ Skimming — vista de pájaro

Leer rápido y por encima para captar la idea general: recorres el título, los encabezados (Requirements, Installation, Usage…) y la primera línea de cada párrafo. En 30 segundos sabes de qué trata la página y si te sirve.

🎯 Scanning — radar de datos

Buscar un dato específico ignorando todo lo demás: un número de versión, un comando, un nombre de archivo. Tus ojos "escanean" el texto buscando números, palabras en negrita o bloques de código.

Como hispanohablante ya conoces muchas palabras del inglés técnico sin saberlo: los cognados son palabras casi iguales en ambos idiomas (application/aplicación, version/versión, error/error, program/programa, system/sistema, connection/conexión). ¡Úsalos como anclas al leer! Pero cuidado: también existen falsos amigos que parecen una cosa y significan otra.

🔑 Palabras clave que verás en casi toda la documentación:

requirements = requisitos

install = instalar

usage = modo de uso

example = ejemplo

note = nota

warning = advertencia

error = error

run = ejecutar

Casi todos los README y páginas de ayuda siguen el mismo esqueleto. Si reconoces las partes, sabes exactamente dónde mirar según lo que necesites. Observa este README de ejemplo de una herramienta imaginaria pero realista, TaskLite, con cada parte etiquetada: 

# TaskLite  TITLE
A simple command-line tool to manage your to-do lists.  DESCRIPTION

## Requirements  REQUIREMENTS
- Python 3.10 or higher
- pip 23 or higher
- 50 MB of free disk space

## Installation  STEPS
1. Open your terminal.
2. Run: pip install tasklite
3. Verify the installation: tasklite --version

## Usage  EXAMPLE
$ tasklite add "Study English"
$ tasklite list

## Note  NOTE
TaskLite saves your tasks in a local file called tasks.json.

## Warning  WARNING
Do not delete tasks.json while the program is running.
You may lose your data.

# PixelBot
A command-line tool to resize and convert images.

## Requirements
- Node.js 18 or higher
- 120 MB of free disk space

## Installation
1. Open your terminal.
2. Run: npm install -g pixelbot
3. Check the version: pixelbot --version

## Usage
$ pixelbot resize photo.png --width 800
Resized images are saved in the ./output folder.

## Warning
Do not close the terminal while PixelBot is converting images.

Recursos para profundizar

Para ampliar tu conocimiento, te recomendamos explorar los siguientes recursos:

  • Practise English reading skills (British Council)

    Textos de práctica de lectura organizados por niveles (A1 a C1) con actividades interactivas gratuitas. Empieza por los niveles A1 y A2.

    Ir al recurso

  • Cambridge Dictionary

    Diccionario inglés-español gratuito con pronunciación y ejemplos. Úsalo para confirmar cognados y desenmascarar falsos amigos mientras lees documentación.

    Ir al recurso

  • Oxford Learner's Dictionaries

    Diccionario para estudiantes de inglés con definiciones sencillas, audio y ejemplos de uso reales. Ideal para el vocabulario clave de las páginas de ayuda.
