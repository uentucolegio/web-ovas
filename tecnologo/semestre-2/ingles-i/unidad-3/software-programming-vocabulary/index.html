Common Software and Programming Vocabulary: las palabras que abren puertas 💻

Piensa en la última vez que instalaste una aplicación o que te salió un mensaje de error en el computador. ¿En qué idioma estaba casi todo? Exacto: en inglés. Palabras como file, download, save, bug o password aparecen todos los días en las pantallas de quien estudia desarrollo de software. La buena noticia es que muchas de ellas ya las has visto mil veces; ahora vas a entenderlas de verdad y a usarlas con confianza.

En este OVA vas a aprender el vocabulario técnico más frecuente del mundo del software: los nombres de los dispositivos (hardware), las acciones con archivos y programas (software), los términos básicos de programación (code, bug, variable, function, loop) y las palabras de la web e internet (browser, server, database). Dominar este vocabulario es la puerta de entrada a la documentación oficial, los tutoriales, los foros como Stack Overflow y las herramientas profesionales que usarás durante toda tu carrera: casi todo está escrito primero en inglés.

No necesitas ser experto en inglés para empezar. Con un nivel básico (A1-A2) y este vocabulario, ya podrás comprender mensajes cortos de tus herramientas y escribir frases sencillas sobre tus primeras tareas como desarrollador o desarrolladora.

✨ Al terminar este OVA, las palabras de tus programas dejarán de ser un misterio: entenderás lo que dice tu computador y podrás responderle en su propio idioma. 🚀

Objetivos de aprendizaje

  • 🧠 Reconocer el vocabulario técnico en inglés más frecuente del software y la programación (hardware, archivos, código, web) en textos y mensajes breves.
  • 💡 Relacionar cada término técnico con su significado y con la función que cumple en las herramientas y tareas iniciales de desarrollo de software.
  • 🔧 Comprender instrucciones y mensajes cortos en inglés que aparecen en interfaces, comandos y programas (por ejemplo: "Save the file" o "Download the app").
  • 📦 Utilizar el vocabulario aprendido para producir oraciones breves y sencillas en inglés sobre herramientas y actividades básicas de programación.

Hardware es todo lo que puedes tocar del computador: la pantalla, el teclado, el ratón… Estas son las palabras que escucharás y leerás a diario en manuales y tutoriales. Fíjate en la pronunciación aproximada (entre barras) y en el ejemplo de uso real:

hardware /járd-uer/

Las partes físicas del computador.

"My laptop has new hardware."

computer /kom-piú-ter/

Computador, la máquina donde programas.

"Turn on the computer, please."

keyboard /kí-bord/

Teclado, tu herramienta principal para escribir código.

"Programmers use the keyboard a lot."

mouse /máus/

Ratón, para mover el cursor y hacer clic.

"Click the button with the mouse."

screen / monitor /skrín/ /mó-ni-tor/

Pantalla, donde ves tu programa funcionando.

"The error message is on the screen."

laptop /láp-top/

Computador portátil.

"I write code on my laptop at the university."

USB drive /iu-es-bí dráiv/

Memoria USB para guardar y llevar archivos.

"Copy the project to the USB drive."

device /di-váis/

Dispositivo: cualquier aparato (celular, tablet, computador).

"This app works on any device."

El software es la parte que no puedes tocar: los programas y aplicaciones. Aquí están las palabras que verás en los menús y ventanas de cualquier programa:

software /sóft-uer/

Los programas del computador.

"We develop software at the university."

app / application /ap/ /a-pli-kéi-shon/

Aplicación, un programa con un propósito específico.

"Download the app from the store."

file /fáil/

Archivo: un documento, imagen o programa guardado.

"Save the file before you close the program."

folder /fóul-der/

Carpeta: contenedor que organiza archivos.

"Put the images in the 'img' folder."

interface /ín-ter-feis/

Interfaz: lo que ves y usas para comunicarte con un programa.

"This app has a simple interface."

download / install /dáun-loud/ /ins-tól/

Descargar / instalar un programa.

"First download the program, then install it."

save /séiv/

Guardar tu trabajo. ¡El verbo más importante!

"Always save your work."

delete /di-lít/

Borrar o eliminar un archivo.

"Don't delete that folder!"

⌨️ Keyboard shortcuts (atajos de teclado)

Los atajos también "hablan inglés": cada letra viene de un verbo. Conocerlos te hace más rápido:

Shortcut Verbo en inglés Acción
Ctrl + Ccopy /kó-pi/Copiar
Ctrl + Vpaste /péist/Pegar
Ctrl + Ssave /séiv/Guardar
Ctrl + Zundo /an-dú/Deshacer

Estas son las palabras del corazón de tu carrera. Las verás en todos los lenguajes de programación, en la documentación y en los mensajes de error. Muchas ni siquiera se traducen: los programadores hispanohablantes dicen "un bug" o "el loop" tal cual:

code /kóud/

Código: las instrucciones que escribes para el computador.

"She writes code in Python."

bug /bag/

Error o fallo en un programa. (¡Literalmente significa "bicho"! 🐛)

"My program has a bug: it shows the wrong number."

variable /vé-ria-bol/

Espacio con nombre que guarda un valor que puede cambiar.

"The variable 'age' stores the user's age."

function /fánk-shon/

Función: bloque de código con nombre que realiza una tarea.

"This function calculates the total price."

loop /lúp/

Bucle o ciclo: código que se repite varias veces.

"The loop repeats the message ten times."

debug /di-bág/

Depurar: buscar y corregir los errores del código.

"We need to debug the program before class."

programmer / developer /pró-gra-mer/ /di-vé-lo-per/

Programador(a) / desarrollador(a): ¡tu futura profesión!

"I want to be a software developer."

run /ran/

Ejecutar un programa (ponerlo a funcionar).

"Run the program and check the result."

💡 Dato curioso: la palabra bug se hizo famosa en 1947, cuando el equipo de la programadora Grace Hopper encontró una polilla real dentro de un computador que fallaba. ¡Desde entonces los errores se llaman "bugs" y corregirlos es "debugging"!

Gran parte del software moderno vive en internet. Estas palabras te acompañarán cuando construyas tus primeras páginas y aplicaciones web:

browser /bráu-ser/

Navegador: el programa para visitar sitios web (Chrome, Firefox…).

"Open the browser and go to the university website."

website /uéb-sait/

Sitio web: un conjunto de páginas en internet.

"Our team is building a website for the project."

server /sér-ver/

Servidor: computador que entrega páginas y datos a otros equipos.

"The website is slow because the server is busy."

database /déi-ta-beis/

Base de datos: donde se guarda la información organizada.

"The app saves the users' names in a database."

link /link/

Enlace: texto o botón que te lleva a otra página.

"Click the link to open the tutorial."

username / password /iú-ser-neim/ /pás-uerd/

Nombre de usuario y contraseña para entrar a un sistema.

"Enter your username and password to log in."

cloud /kláud/

La nube: servicios y archivos guardados en internet.

"My photos are in the cloud, not on my laptop."

log in / log out /log in/ /log áut/

Iniciar / cerrar sesión en un sistema.

"Log out when you finish using the computer."
