Clases, objetos, atributos, métodos y constructores 🧩

La programación orientada a objetos (POO) organiza el software mediante clases y objetos que representan entidades del mundo real. Este enfoque facilita el desarrollo de aplicaciones organizadas, reutilizables y fáciles de mantener.

✨ Hoy pasarás de observar objetos cotidianos a diseñar tus propias piezas de software. 🚀

Objetivos de aprendizaje 🎯

  • 🧠Identificar los conceptos de clase, objeto, atributo, método y constructor.
  • 🔎Diferenciar una clase de un objeto mediante ejemplos.
  • 🛠️Modelar problemas sencillos utilizando los principios básicos de la POO.
📘 Primero: construye el mapa mental

De una idea a muchos objetos

Imagina el plano de una casa y las casas construidas con él. El plano define una estructura común; cada casa ocupa su propio espacio y puede tener valores distintos. Esa relación ayuda a comprender cómo se organiza un programa orientado a objetos.

🗂️ El tipo que organiza

Una clase reúne una descripción de datos y operaciones relacionadas. Sirve como un tipo creado por el programador: establece qué tendrán en común sus futuras instancias.

Ejemplo: Bicicleta puede definir color, velocidad y las acciones acelerar o frenar.

🚲 La entidad que existe

Cada instancia tiene identidad y su propio estado. Dos bicicletas pueden provenir de la misma definición, pero una ser verde y rápida mientras otra es roja y está detenida.

Idea clave: compartir estructura no significa compartir todos los valores.

Anatomía de un objeto 🔬

🪪

Identidad

Permite distinguir una instancia de otra, incluso si sus datos coinciden.

📊

Estado

Es el conjunto de valores actuales almacenados en sus campos.

⚙️

Comportamiento

Son las operaciones que puede ejecutar y que quizá cambian su estado.

Campos: datos de instancia y de clase 📦

Un dato de instancia pertenece a cada objeto: cada libro conserva su título. Un dato de clase o static se comparte: un contador puede registrar cuántos libros fueron creados.

Instancia
libro1.titulo ≠ libro2.titulo
Clase
Libro.totalCreados

Métodos: mensajes con intención 📣

Un método tiene nombre, cero o más parámetros, un cuerpo y un tipo de retorno; void indica que no devuelve un valor. Los buenos nombres suelen expresar acciones: prestar(), calcularMulta(dias).

Parámetro: dato que entra. Retorno: resultado que sale. Efecto: cambio que puede producir.

El nacimiento de una instancia 🌱

1. Declarar

Se define una referencia.

2. Instanciar

new reserva el objeto.

3. Inicializar

El constructor asigna valores.

4. Usar

La referencia invoca métodos.

Oracle distingue estas etapas al crear objetos en Java. Una variable de referencia por sí sola todavía no crea una instancia.

Tres pasos para crear y usar un objeto Java 💻

Declarar
Libro a;
Instanciar
a = new Libro("1984");
Usar
System.out.println(a.consultarTitulo());

En Java el constructor tiene el mismo nombre que la clase y no declara tipo de retorno; new Libro("1984") crea e inicializa la instancia.

Caso: aplicación de domicilios 🛵

  • Posibles tipos: Cliente, Pedido, Restaurante y Repartidor.
  • Instancias: “Pedido #501” y “Restaurante La Esquina”.
  • Estado del Pedido: dirección, total y estado.
  • Operaciones: agregarProducto(), calcularTotal() y confirmar().

Errores que confunden 🧯

  • ❌ Creer que declarar una referencia crea el objeto.
  • ❌ Poner acciones como atributos: vender sin ().
  • ❌ Crear un tipo por cada ejemplar: Libro1984, LibroQuijote…
  • ❌ Usar el constructor para tareas ajenas a la inicialización.
  • ✅ Modelar sustantivos como clases y verbos útiles como métodos.

Esperando ejecución…

Dos variables pueden apuntar al mismo objeto. Predice qué mostrará el código.

class Libro {
  private String titulo;
  Libro(String titulo) { this.titulo = titulo; }
  void cambiarTitulo(String titulo) { this.titulo = titulo; }
  String consultarTitulo() { return titulo; }
}
class Referencias {
  public static void main(String[] args) {
    Libro libroA = new Libro("1984");
    Libro libroB = libroA;
    libroB.cambiarTitulo("Rebelión en la granja");
    System.out.println(libroA.consultarTitulo());
  }
}
