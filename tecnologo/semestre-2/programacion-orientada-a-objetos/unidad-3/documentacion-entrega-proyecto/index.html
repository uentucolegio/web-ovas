Documentación y entrega del proyecto 🚀

Un proyecto funciona en el equipo de su autor, pero otra persona desconoce la versión de Java, la clase principal y los pasos para reproducir resultados. Aunque el código sea correcto, la entrega carece de información necesaria para utilizarlo y evaluarlo.

Documentar conserva decisiones y contratos para quienes ejecutan, revisan y mantienen software. No significa comentar cada instrucción. Una explicación útil responde una pregunta concreta: qué garantiza una operación, por qué existe una restricción o cómo comprobar el resultado.

Se utiliza Java 17 y un control de cupos en memoria. Se integran documentación de API, instrucciones, pruebas y organización de recursos. El proyecto estará listo cuando una persona diferente pueda seguir el procedimiento, reconocer el alcance y distinguir lo comprobado de lo pendiente.

/**
* Controla cupos en memoria; no ofrece seguridad entre hilos.
*/
public class CuposProyecto {
    private int cupos;

    /**
    * Crea un control con la capacidad indicada.
    * @param capacidad cupos iniciales, admite cero
    * @throws IllegalArgumentException si capacidad es negativa
    */
    public CuposProyecto(int capacidad) {
        if (capacidad < 0) {
            throw new IllegalArgumentException("Capacidad negativa");
        }
        cupos = capacidad;
    }

    /**
    * Reserva un cupo; un rechazo conserva el estado.
    * @return cupos restantes despues de reservar
    * @throws IllegalStateException si no quedan cupos
    */
    public int reservar() {
        if (cupos == 0) {
            throw new IllegalStateException("Sin cupos");
        }
        return --cupos;
    }

    /**
     * Consulta la disponibilidad sin modificar el estado.
     * @return cantidad de cupos disponibles
     */
    public int disponibles() { return cupos; }

    /**
    * Ejecuta una demostracion determinista.
    * @param args argumentos de consola no utilizados
    */
    public static void main(String[] args) {
        CuposProyecto control = new CuposProyecto(1);
        System.out.println(control.disponibles());
        System.out.println(control.reservar());
        try {
            control.reservar();
        } catch (IllegalStateException e) {
            System.out.println(e.getMessage());
        }
        System.out.println(control.disponibles());
    }
}
