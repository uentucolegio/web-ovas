Manejo de errores y validación de datos 🚀

Un formulario recibe una edad. El texto puede estar vacío, contener letras, representar un entero demasiado grande o indicar un número fuera del rango acordado. Todos esos casos producen un rechazo, pero las causas y las respuestas útiles son diferentes.

Validar consiste en decidir si un dato satisface reglas declaradas. Manejar un error consiste en responder cuando una operación no puede terminar como se esperaba. Ambas tareas se complementan: una protege el dominio y la otra permite comunicar el problema o recuperar un flujo.

Se utiliza Java 17 y un registro con edades entre 0 y 120 años. Ese intervalo es una regla didáctica explícita, no una definición universal de edad válida. Se presuponen métodos, condiciones y constructores. Las entradas del programa son deterministas para facilitar su comprobación.

🎮 Reto de 10 puntos: ¿En qué etapa se rechaza -1?

Una cadena puede contener solo dígitos y superar Integer.MAX_VALUE. Integer.parseInt rechaza ese desbordamiento. Cambiar a long no elimina la regla de edad. Normalizar espacios extremos no equivale a borrar espacios internos.

🎮 Reto de 10 puntos: ¿Cómo se clasifica 2147483648 con Integer.parseInt?

throw lanza; throws declara propagación. NumberFormatException hereda de IllegalArgumentException. Captura tipos específicos primero. Conserva la causa cuando traduces el fallo y evita convertir un error en un valor de negocio inventado.

🎮 Reto de 10 puntos: ¿Qué conserva el diagnóstico al traducir un fallo?

Valida nombre y edad en variables locales; construye e inserta solo al terminar. Si antes había dos registros y la entrada falla, después deben seguir existiendo dos. Un catch no deshace una inserción previa.

🎮 Reto de 10 puntos: ¿Qué debe comprobar una prueba de registro inválido?

La interfaz puede pedir una corrección; el dominio protege invariantes. Para AutoCloseable usa try-with-resources. finally no revierte negocios ni es una garantía ante terminación abrupta. No captures Error como si fuera un dato equivocado.

public class RegistroSeguro {
    static int convertirEdad(String texto) {
        if (texto == null || texto.trim().isEmpty()) {
            throw new IllegalArgumentException("Edad requerida");
        }
        final int edad;
        try {
            edad = Integer.parseInt(texto.trim());
        } catch (NumberFormatException causa) {
            throw new IllegalArgumentException(
            "Edad: entero representable requerido", causa);
        }
        if (edad < 0 || edad > 120) {
            throw new IllegalArgumentException("Edad fuera de 0..120");
        }
        return edad;
    }
    public static void main(String[] args) {
        String[] entradas = {" 18 ", "0", "120", "121", "abc", null};
        for (String entrada : entradas) {
            try {
                System.out.println("OK " + convertirEdad(entrada));
            } catch (IllegalArgumentException e) {
                System.out.println("ERROR " + e.getMessage());
            }
        }
    }
}
