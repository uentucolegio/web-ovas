# Lista de revisión: Principios SOLID introductorios

- [ ] Cada clase tiene un motivo de cambio explicado.
- [ ] El consumidor usa un contrato sin consultar tipos concretos.
- [ ] Se prueban cero, límites y argumentos inválidos.
- [ ] Las políticas respetan el intervalo común.
- [ ] La regla de redondeo está escrita.
- [ ] Las abstracciones añadidas resuelven variaciones concretas.

Esta lista es una ayuda para autorrevisión, no una certificación automática.
