# Rúbrica orientativa

Cada criterio: 0 ausente; 1 parcial; 2 completo y respaldado. Total: 10 puntos.

1. Contrato explícito: entradas, salidas y efectos.
2. Casos normales, límites y fallos justificados.
3. Código Java reproducible y nombres claros.
4. Evidencia real separada de predicciones.
5. Explicación de decisiones y limitaciones.

La puntuación la asigna quien revisa el producto; marcar una casilla en el OVA no la asigna automáticamente.
