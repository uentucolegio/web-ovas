# Fichas de repaso

## Oráculo

Criterio independiente que determina si el resultado cumple el requisito.

## AAA

Preparar datos, actuar sobre el comportamiento y comprobar el resultado.

## Valor límite

Un extremo y sus vecinos ayudan a detectar operadores de comparación equivocados.

## Prueba parametrizada

Repite el mismo comportamiento con filas de datos, manteniendo esperados explícitos.

## Mutante

Variante del código con un pequeño defecto intencional para comprobar la sensibilidad de la suite.

## Cobertura

Mide recorrido de código, pero no demuestra la calidad de las aserciones.
