# Lista de revisión: Pruebas unitarias introductorias

- [ ] Los esperados se deducen de requisitos.
- [ ] Los casos son independientes.
- [ ] Hay aceptación y rechazo.
- [ ] Se prueban extremos y vecinos.
- [ ] Se comprueba el estado después de fallos.
- [ ] Se registra cuántas pruebas se descubrieron y ejecutaron.

Esta lista es una ayuda para autorrevisión, no una certificación automática.
