# Imágenes QR necesarias

Este directorio debe contener las siguientes imágenes QR para la sección de Recursos:

- **qr-ieee.png** - Código QR para el recurso "Guía de Requisitos de Software - IEEE"
- **qr-chaos.png** - Código QR para el recurso "CHAOS Report - Standish Group"
- **qr-iso.png** - Código QR para el recurso "ISO/IEC 25010 - Calidad del Software"
- **qr-tecnicas.png** - Código QR para el recurso "Técnicas de Ingeniería de Requisitos"

**Instrucciones:**
1. Genera los códigos QR correspondientes a las URLs especificadas en el archivo index.html
2. Guarda cada imagen con el nombre exacto indicado arriba
3. Formato recomendado: PNG, tamaño 2cm x 2cm (aprox 75x75 píxeles a 96 DPI)

**URLs de los recursos:**
- IEEE: https://ieeexplore.ieee.org/document/
- CHAOS Report: https://www.standishgroup.com/
- ISO/IEC 25010: https://iso25000.com/index.php/en/iso-25000-standards/iso-25010
- Técnicas: https://www.requirementsengineering.com
